SVD Digit Denoising

Using Singular Value Decomposition (SVD) and low-rank reconstruction to recover structure from noisy handwritten digits.

Completed

Project question

How much noise and dimensional complexity can be removed while preserving the recognizable structure of an image?

Approach

The project uses SVD to decompose image data into singular components, studies cumulative singular-value energy, reconstructs lower-rank approximations and evaluates denoising quality.

Why it matters

The project makes a core linear-algebra idea visible: high-dimensional data often contains structure that can be represented with fewer dimensions than the original data suggests.
