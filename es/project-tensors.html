Tensors 101 with PyTorch

Una serie educativa de cuatro notebooks diseñada para ayudar a los estudiantes a comprender tensors en profundidad —no solamente a utilizarlos— conectando estructura matemática, sintaxis de PyTorch y la forma en que los datos fluyen a través de Neural Networks.

Proyecto educativo

1. Por qué Tensors importan

Un tensor es la estructura de datos básica utilizada en modern Deep Learning. Images, tabular records, sequences, model parameters, activations y gradients se representan como tensors. El propósito principal de este proyecto educativo es avanzar desde la idea de un simple número hacia higher-dimensional data structures y después mostrar cómo esas estructuras se manipulan dentro de PyTorch.

Idea clave: tensors no son un objeto especial de “AI” desconectado de las matemáticas. Generalizan scalars, vectors y matrices a un número arbitrario de dimensions.

2. La Tensor Hierarchy

Objeto Tensor rank Example shape Interpretación típica
Scalar 0D () Un solo número, por ejemplo temperature = 42.5
Vector 1D (4,) Cuatro patient measurements o cuatro features
Matrix 2D (3, 4) Tres observations con cuatro variables cada una
3D tensor 3D (3, 224, 224) Color image: channels × height × width
4D tensor 4D (32, 3, 224, 224) Batch de 32 color images
5D tensor 5D (8, 20, 3, 224, 224) Batch de videos con frames e image channels

3. Rank, Axes, Shape y Element Count

Estos términos están relacionados, pero no significan lo mismo.

Rank / ndim

Número de axes del tensor. Una matrix tiene rank 2 porque posee dos axes.

Axis

Una dirección dentro de los datos. Para shape (32, 3, 224, 224), axis 0 es batch, axis 1 es channel, axis 2 es height y axis 3 es width.

Shape

Tuple que contiene la longitud de cada axis. Shape describe completamente la organización de los valores.

numel

Número total de scalar values. Es igual al producto de todas las shape dimensions.

numel = d₁ × d₂ × ··· × dₙ
Si un tensor tiene shape (2, 3, 4), entonces numel = 2 × 3 × 4 = 24.
Mini ejemplo. Un tensor con shape (4, 5, 6) tiene rank 3 y contiene 4 × 5 × 6 = 120 elements.

4. Por qué Shape es uno de los conceptos más importantes en Deep Learning

Neural-network layers esperan datos en formatos estructurales específicos. Una gran proporción de los errores de principiantes proviene de shape mismatches, no de fallos matemáticos complejos.

(batch, features)
Typical fully connected/tabular input.
(batch, channels, height, width)
Typical PyTorch image input.
(batch, sequence length, embedding dimension)
Typical sequence representation.
Shape reasoning example. Supongamos que x tiene shape (4, 5, 6). Si calculamos x.sum(dim=1), axis 1 desaparece porque los valores a lo largo de su dimensión de longitud 5 se suman. El output shape se convierte en (4, 6).

5. Data Types: ¿qué está almacenado dentro del Tensor?

Todo tensor posee un dtype que determina cómo se representan los valores en memory. Esto afecta precision, memory usage y compatibilidad con PyTorch operations.

dtype Uso típico Por qué importa
torch.float32 Model inputs, parameters, activations y gradients Balance estándar entre precision y memory para Deep Learning.
torch.float16 Mixed-precision training Utiliza menos memory y puede acelerar workloads compatibles con GPU.
torch.int64 Class labels e indices Muchas PyTorch loss functions requieren integer class labels.
torch.bool Masks y conditions Útil para seleccionar o excluir elements.
Por qué dtype importa: un model con 100 million parameters utiliza aproximadamente 400 MB solo para parameter values en float32, pero alrededor de 200 MB en float16. Las decisiones sobre precision tienen consecuencias computacionales reales.

6. Devices: CPU y GPU

Un tensor debe existir físicamente en algún lugar. En PyTorch, normalmente significa CPU memory o GPU memory. Las operations requieren que los tensors participantes estén en el mismo device.

device = torch.device("cuda" if torch.cuda.is_available() else "cpu") x = torch.randn(32, 10, device=device)
Error común: sumar un CPU tensor con un GPU tensor produce un device mismatch error. Device management no es opcional en GPU-based workflows.

7. Creating Tensors

PyTorch ofrece varias estrategias para crear tensors. El objetivo educativo no es memorizar comandos, sino comprender cuándo corresponde utilizar cada uno.

torch.tensor([1.0, 2.0, 3.0]) # from known values torch.zeros(3, 4) # all zeros torch.ones(3, 4) # all ones torch.eye(4) # identity matrix torch.arange(0, 10) # integer sequence torch.linspace(0, 1, 5) # evenly spaced sequence torch.rand(3, 4) # uniform random values torch.randn(3, 4) # standard normal random values

Para reproducibility, los notebooks también enfatizan establecer una random seed:

torch.manual_seed(42)

8. Indexing y Slicing

Indexing solicita elements o regiones específicas de un tensor. El número de indices requeridos refleja el rank del tensor.

x[i, j, k]
Para un rank-3 tensor, tres indices identifican un scalar element.

Slicing permite conservar axes mientras se seleccionan ranges. Esto importa al seleccionar un batch, subset of features, image region o sequence window.

Mini ejemplo. Si x tiene shape (32, 10), entonces x[:, 0] selecciona la primera feature para las 32 observations y devuelve shape (32,).

9. Reshaping: cambiar la estructura sin cambiar los datos

Muchas Deep Learning operations requieren reorganizar los mismos números en una shape diferente. Un reshape es válido solamente si se conserva el total element count.

∏ old dimensions = ∏ new dimensions
Mini ejemplo. Un tensor de shape (2, 3, 4) contiene 24 elements. Puede reshaped a (6, 4), (8, 3), (24,) o (1, 24), porque todas esas formas contienen 24 values.

Algunas herramientas importantes de PyTorch incluyen reshape(), view(), unsqueeze(), squeeze(), transpose() y permute().

view() vs reshape(): view() requiere un contiguous memory layout. reshape() es más flexible porque puede crear una copy cuando es necesario.

10. Broadcasting: matemáticas entre compatible shapes

Broadcasting permite que PyTorch aplique element-wise operations a tensors con shapes diferentes pero compatibles. Comenzando desde la última dimension y avanzando hacia la izquierda, dos dimensions son compatibles si son iguales, una de ellas es 1, o uno de los tensors no posee una dimension correspondiente.

Broadcasting example.

A tiene shape (3, 4) y b tiene shape (4,).
PyTorch interpreta b como si se repitiera a lo largo de las tres rows.
El resultado A + b tiene shape (3, 4).
Por qué Broadcasting importa: Neural Networks agregan constantemente bias vectors a batches de activations. Broadcasting permite hacerlo eficientemente sin duplicar físicamente el bias vector.

11. Element-wise Operations versus Matrix Multiplication

Estas son operations matemáticamente diferentes y una de las distinciones más importantes para principiantes.

Element-wise: Cᵢⱼ = Aᵢⱼ Bᵢⱼ
En PyTorch: A * B
Matrix product: Cᵢⱼ = Σₖ Aᵢₖ Bₖⱼ
En PyTorch: A @ B o torch.matmul(A,B)
Matrix multiplication example. Si A tiene shape (5, 3) y B tiene shape (3, 2), las inner dimensions coinciden, por lo que A @ B tiene shape (5, 2).

12. Reduction Operations

Una reduction combina múltiples values en una cantidad menor de values. Algunos ejemplos incluyen sum, mean, maximum y minimum.

mean(x) = (1/n) Σᵢ xᵢ

La pregunta esencial siempre es: ¿a lo largo de qué axis?

Mini ejemplo. Si x tiene shape (32, 10), entonces x.mean(dim=0) calcula una mean para cada feature a través de las 32 observations y devuelve shape (10,).

13. Activation Functions

Activation functions introducen nonlinearity en Neural Networks. Sin nonlinear activations, múltiples linear layers apiladas todavía colapsarían en una sola linear transformation.

Function Formula Interpretación
ReLU ReLU(x)=max(0,x) Conserva positive values y lleva negative values a cero.
Sigmoid σ(x)=1/(1+e−x) Mapea cualquier real number al intervalo (0,1); suele usarse para binary probabilities.
Tanh tanh(x) Mapea values al intervalo (−1,1) y está centrada en cero.

14. Cómo los Tensors fluyen a través de una Neural Network

Una dense neural-network layer aplica una affine transformation seguida de una activation function:

z = XW + b a = φ(z)
X = batch de input features, W = weight matrix, b = bias vector, φ = activation function.
Shape example.

Input X: (32, 10)
Weights W: (10, 64)
Bias b: (64,)
Matrix product XW: (32, 64)
Broadcast b across 32 rows → output z: (32, 64).

Este solo ejemplo combina matrix multiplication, shape reasoning y broadcasting: las tres ideas de tensors que un estudiante debe comprender antes de avanzar con confianza hacia Neural Networks.

15. Automatic Differentiation: por qué PyTorch Tensors son más que Arrays

Cuando requires_grad=True, PyTorch registra operations dentro de un computational graph. Durante backpropagation, aplica Chain Rule para calcular cómo cambia una loss respecto de los model parameters.

∂L/∂w = (∂L/∂y)(∂y/∂w)
Esta es la Chain Rule detrás de gradient-based learning.
w = torch.tensor(2.0, requires_grad=True) y = w**2 y.backward() print(w.grad) # 4.0

Como y = w², la derivative es dy/dw = 2w. Cuando w = 2, el gradient es 4.

16. Common Tensor Mistakes que este proyecto ayuda a prevenir

  • Confundir rank con el número de elements.
  • Ignorar la batch dimension.
  • Intentar matrix multiplication con incompatible inner dimensions.
  • Mezclar CPU y GPU tensors.
  • Usar el dtype incorrecto para class labels.
  • Aplicar view() a non-contiguous tensors.
  • Hacer reshaping sin verificar que se conserve el total number of elements.
  • Realizar reduction sobre el axis equivocado.
  • Confundir element-wise multiplication con matrix multiplication.
  • Depender del código sin predecir primero el output shape.
