Mathematics for Data Science

Una ruta estructurada para comprender la matemática que sostiene Data Science, Machine Learning y Deep Learning desde una perspectiva visual y aplicada.

Recursos → Mathematics for Data Science

De vectores y matrices a optimización.

Esta ruta comienza con Scalars, Vectors and Matrices y desarrolla gradualmente operaciones vectoriales, Matrix Multiplication, Linear Systems, Linear Transformations, Orthogonality y Least Squares.

Después conecta Eigenvalues, Covariance Matrices, PCA y SVD con la geometría de los datos, antes de introducir Calculus, Partial Derivatives, Gradients, Chain Rule y Optimization.

Orden de aprendizaje recomendado: sigue las guías en secuencia. Cada bloque prepara las ideas matemáticas necesarias para comprender el siguiente.
Guías

Secuencia de aprendizaje

El recorrido sigue una progresión intencional: Vectors → Matrices → Linear Systems → Projections → Eigenvalues → PCA → SVD → Calculus → Gradients → Optimization.

Guía visual: azul = vectores y fundamentos, verde = matrices y transformaciones, violeta = eigenvalues, PCA y SVD, naranja = calculus y gradients, rojo = optimization.

¿Por qué este orden?

Primero construimos el lenguaje geométrico de los datos mediante vectores y matrices. Después estudiamos sistemas lineales, transformaciones, independencia, rank, orthogonality y projections para comprender cómo se organiza la información en espacios vectoriales.

Con esa base, Eigenvalues, Covariance Matrices, PCA y SVD dejan de parecer técnicas aisladas: se convierten en distintas formas de describir estructura, variación y direcciones importantes en los datos.

Finalmente, Calculus, Partial Derivatives, Gradients, Chain Rule y Optimization permiten comprender matemáticamente cómo muchos modelos de Machine Learning ajustan sus parámetros y minimizan una función de pérdida.
