Machine Learning

Una ruta estructurada para comprender cómo se construyen, entrenan, evalúan, explican y llevan a producción modelos de Machine Learning.

Recursos → Machine Learning

De los fundamentos del aprendizaje a modelos reproducibles y explicables.

Esta ruta comienza diferenciando supervised y unsupervised learning, classification y regression, y después desarrolla el workflow completo de Machine Learning.

A partir de allí avanzamos hacia Linear Regression, Logistic Regression, Loss Functions, Gradient Descent, regularization, feature engineering, preprocessing, trees, ensembles, model selection, explainability y deployment.

Orden de aprendizaje recomendado: sigue las guías en secuencia. La ruta está diseñada para que cada tema utilice ideas introducidas previamente.
Guías

Secuencia de aprendizaje

El recorrido sigue una progresión intencional: Machine Learning Foundations → Regression & Classification → Loss Functions → Gradient Descent → Regularization → Feature Engineering → Preprocessing → Decision Trees → Ensembles → Hyperparameter Tuning → Cross-Validation → Explainability → Pipelines → Deployment.

¿Por qué este orden?

Primero necesitamos comprender qué tipo de problema estamos resolviendo, qué aprende realmente un modelo y cómo se representa el error. Por eso comenzamos con supervised learning, regression, classification, Linear Regression, Logistic Regression y Loss Functions.

Después estudiamos cómo aprende el modelo mediante Gradient Descent y cómo controlar complejidad mediante Regularization. Luego incorporamos Feature Engineering, missing data y scaling para comprender el papel del preprocessing.

Con esa base, Decision Trees, Random Forest, Bagging, Boosting y XGBoost pueden estudiarse como familias de modelos relacionadas. Finalmente incorporamos Hyperparameter Tuning, Cross-Validation, Feature Importance, SHAP, Class Imbalance, Pipelines y Deployment para conectar el aprendizaje académico con un workflow real de Machine Learning.
