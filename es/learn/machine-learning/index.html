Machine Learning

Un curso completo de 33 guías diseñado para construir comprensión de Machine Learning desde los fundamentos hasta modelado moderno, evaluación, interpretabilidad, reproducibilidad y Deployment.

Learn → Machine Learning

Aprende cómo funciona Machine Learning: desde los fundamentos hasta sistemas completos.

Este curso de 33 guías está organizado como una secuencia académica acumulativa. Comienza definiendo los problemas de aprendizaje y el workflow de principio a fin, y luego desarrolla las bases matemáticas y de preparación de datos necesarias para comprender cómo los modelos se ajustan, optimizan, generalizan y fallan.

Después, el curso avanza por modelos lineales y probabilísticos, métodos basados en similitud, Support Vector Machines, árboles y ensembles, Neural Networks, aprendizaje no supervisado, Time Series y Reinforcement Learning. Las guías finales conectan interpretabilidad, reproducibilidad responsable y el ciclo completo de producción.

Orden recomendado: sigue las Guías 1–33 en secuencia. Cada guía profundiza ideas anteriores y prepara los prerrequisitos necesarios para los temas posteriores.

¿Por qué este orden?

Las Guías 1–6 establecen el lenguaje de Machine Learning, distinguen los tipos de problemas de predicción, presentan el workflow completo y desarrollan las bases matemáticas, de preparación de datos y de evaluación necesarias para evitar resultados engañosos.

Las Guías 7–14 desarrollan la mecánica de Statistical Learning: Linear Regression, Loss Functions, Gradient Descent, Logistic Regression, Generalized Linear Models, evaluación, Regularization y teoría de generalización. Las Guías 15–22 permiten después comparar las principales familias de modelos clásicos y estrategias de ensemble dentro de un marco común de evaluación.

Las Guías 23–27 extienden el curso hacia Neural Networks y aprendizaje no supervisado, incluyendo Clustering, Dimensionality Reduction, Gaussian Mixture Models, Anomaly Detection y Association Rules. Las Guías 28–30 introducen forecasting temporal y toma de decisiones secuenciales, donde ya no bastan los supuestos de predicción estática y partición aleatoria.

Las tres guías finales se concentran en comprender el comportamiento del modelo, construir Pipelines reproducibles y responsables, y conectar un notebook validado con Deployment, Monitoring, mantenimiento y Rollback seguro. El objetivo no es solamente conocer algoritmos, sino comprender cómo se razona, evalúa y mantiene un sistema completo de Machine Learning.
