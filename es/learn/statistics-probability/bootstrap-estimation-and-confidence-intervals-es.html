01Por qué resulta útil remuestrear

Una gerente de servicios dispone de doce tiempos de espera y desea describir la incertidumbre de una media poblacional estimada. Calcular el promedio resulta sencillo; comprender cuánto cambiaría entre muestras nuevas es otro problema. Las guías anteriores obtuvieron errores estándar e intervalos de confianza mediante distribuciones teóricas. Aquí construiremos una distribución de estimaciones recalculadas al remuestrear los registros observados. Esto ofrece una vía práctica cuando la fórmula de incertidumbre es incómoda y una comprobación útil cuando sí existe una fórmula analítica.

El bootstrap sustituye la distribución poblacional desconocida por una distribución estimada a partir de la muestra. Después imita el muestreo repetido desde esa población estimada. La palabra esencial es sustituye: el mundo simulado se parece a los datos observados porque lo construimos así deliberadamente. Su incertidumbre resulta informativa cuando la muestra original y el esquema de remuestreo representan razonablemente el proceso real de muestreo. Una simulación visualmente convincente no demuestra por sí sola esa relación.

Al terminar podrás construir una réplica a mano, calcular su estadístico, explicar el error estándar y el sesgo bootstrap estimado, formar un intervalo percentil, compararlo con un intervalo teórico e identificar situaciones que requieren otra unidad de remuestreo. También demostrarás un fallo al estimar un extremo poblacional. Ese contraejemplo importa tanto como los cálculos correctos: evita tratar un algoritmo como garantía universal.

Lee las explicaciones matemáticas antes de los bloques opcionales de Python. Basta Cálculo I; los puentes localizados presentan notación condicional y cuantiles empíricos. Las guías 24,26 y 34 aportan los prerrequisitos principales: promedios Monte Carlo, estimación puntual e intervalos de confianza. Aquí retomamos esas ideas cuando hacen falta para que la notación no se convierta en un obstáculo oculto.

02Definir el objetivo antes de simular

El estimando es la cantidad poblacional que responde la pregunta. Sea μ el tiempo medio de espera de una población de servicios definida explícitamente durante un período operativo estable. El estimador es la regla X̄=(X₁+⋯+Xn)/n, aleatoria antes de recolectar datos. La estimación x̄ es el número obtenido con la muestra observada. Para la mediana, el objetivo poblacional es una mediana m y el estimador es la mediana muestral. Cambiar el estadístico cambia la pregunta inferencial aunque los datos originales sean idénticos.

Los doce valores de este caso didáctico son construidos, no registros observados de un servicio. Suponemos que representan clientes independientes extraídos bajo iguales condiciones, con mediciones completas en minutos. Este supuesto hace coherente usar el bootstrap ordinario de filas independientes como ilustración. No inferimos el desempeño de un servicio real a partir de estas observaciones inventadas. Después cambiaremos deliberadamente el diseño para entender cuándo deja de ser coherente ese remuestreo.

Una réplica bootstrap es una estimación calculada con un conjunto remuestreado. Escribimos θ̂ para la estimación original y θ̂*b para la estimación de la réplica b. El asterisco identifica el mundo de muestreo simulado; no indica multiplicación, una estimación mejorada ni un cliente adicional observado. El subíndice b enumera repeticiones; el índice i identifica observaciones dentro de un conjunto. Confundir ambos lleva a creer erróneamente que producir más réplicas aumenta el tamaño muestral original.

04Construir la distribución empírica

Imagina que colocas cada identificador de fila observada en una bolsa. Una extracción uniforme selecciona uno de los n identificadores con probabilidad 1/n y devuelve el valor asociado. Esta operación define la distribución empírica, escrita Fn. Asigna masa de probabilidad 1/n a cada fila observada. Si varias filas contienen el mismo valor, sus masas se suman. Un valor observado dos veces entre doce filas recibe probabilidad total 2/12, no 1/12. Extraer uniformemente solo valores distintos cambiaría la distribución.

Su función de distribución acumulada indica la fracción de observaciones menores o iguales que un umbral t. El indicador 1{xi≤t} vale 1 cuando se cumple la condición y 0 en caso contrario. Por tanto,

Fn(t)=(1/n)Σi 1{xi≤t}=número de valores observados≤t dividido entre n.

Para t=20 minutos, seis esperas son menores o iguales que 20: Fn(20)=6/12=.5. Para t=25, ocho cumplen la condición: Fn(25)=8/12=2/3. Para t=58, cumplen las doce y Fn(58)=1. Entre valores observados la función permanece constante. Los saltos codifican probabilidades; la pendiente de los escalones conectados no es una densidad de probabilidad.

¿Por qué usar esta distribución? Conserva cada valor observado y su frecuencia sin especificar una familia Normal, Gamma u otra familia paramétrica. Es una aproximación basada en datos a la distribución poblacional desconocida F. Este paso estima una distribución; no afirma que la población solo pueda tomar los doce valores observados. Un cliente real nuevo podría esperar 70 minutos; una extracción bootstrap no paramétrica desde este Fn no puede hacerlo. La diferencia explicará el fallo del bootstrap ingenuo para extremos poblacionales.

05Separar tres distribuciones diferentes

La distribución de los datos observados describe esperas individuales. Su dispersión corresponde a variación entre clientes; aquí su desviación estándar empírica es √171.5≈13.095801 minutos. La distribución muestral de un estimador describe estimaciones obtenidas al recolectar repetidamente n clientes nuevos de la población real F. Su dispersión es el verdadero error estándar del estimador, generalmente desconocido. La distribución bootstrap describe estimaciones al extraer repetidamente n filas del Fn observado y fijo. Bajo condiciones apropiadas, su dispersión estima la dispersión muestral desconocida.

Estas distribuciones colocan objetos distintos en el eje horizontal. En un histograma de las doce esperas cada contribución corresponde a una medición individual. En un histograma de medias bootstrap cada contribución corresponde a una media de doce extracciones. Una distribución estrecha de medias no implica que las esperas individuales estén poco dispersas. Refleja el efecto de promediar junto con el mecanismo de muestreo supuesto.

La notación E* y Var* representa esperanza y varianza condicionadas a la muestra observada. En ese cálculo, los doce números originales permanecen fijos y varían los índices de remuestreo. En cambio, EF y VarF se refieren a muestras originales repetidas bajo la distribución poblacional real. La simulación condicional puede ser exacta respecto de Fn y, aun así, aproximar mal el experimento poblacional que interesa.

Para la media, comparamos X̄*−x̄ bajo Fn con X̄−μ bajo F. Ambas son diferencias de estimación respecto del centro pertinente. Comparar distribuciones sin centrar e ignorar sus centros diferentes puede ocultar el principio. Cuando existe consistencia bootstrap, se refiere a esa aproximación condicional al aumentar la muestra original. No aparece simplemente por tomar infinitas réplicas de una muestra inadecuada.

06El algoritmo bootstrap de n extracciones

Mantén fijo el vector original x. Para la réplica b, extrae independientemente n índices Jb 1,…, Jbn uniformes entre 1,…, n, con reemplazo. Forma x*bj=xJbj, calcula exactamente el estadístico aplicado a los datos originales y guárdalo. Repite para b=1,…, B. Cada réplica contiene n entradas aunque algunas filas originales se repitan y otras falten. La expresión n de n se refiere al tamaño de cada réplica, no al número B de repeticiones.

Para la media, suma los n valores seleccionados y divide entre n. Para la mediana, ordena los valores seleccionados y aplica la convención declarada. No cambies de estadístico a mitad del proceso ni combines datos originales y bootstrap como si fueran un conjunto mayor. El bootstrap estima el comportamiento del procedimiento original de estimación. Si modificas ese procedimiento, cambias el objeto cuya incertidumbre estudias.

08Por qué se esperan repeticiones y ausencias

Una fila determinada tiene probabilidad 1−1/n de no salir en una extracción. La independencia de las n extracciones de índices hace que su probabilidad de faltar en toda la réplica sea (1−1/n)n. La probabilidad de aparecer al menos una vez es 1−(1−1/n)n. Al multiplicar por n obtenemos el número esperado de identificadores distintos representados en una réplica:

E*(IDs distintos)=n[1−(1−1/n)n].

Para n=12, la probabilidad de inclusión es 1−(11/12)¹²≈.648004; por tanto, se esperan aproximadamente 7.776052 identificadores distintos. La réplica sigue teniendo 12 entradas. Identificadores distintos y entradas totales son conteos diferentes. Al crecer n, la fracción esperada representada tiende a 1−e^(−1)≈.632121. Esta fracción describe selección repetida de índices; no afirma que exactamente 63.2% de cada réplica sea único.

Los duplicados son una característica necesaria del remuestreo ordinario, no registros corruptos que deban eliminarse después de extraer. Quitarlos modificaría tanto el tamaño de la réplica como la distribución del estadístico. Los valores originales repetidos requieren otra distinción: dos clientes diferentes pueden registrar igual espera. Siguen siendo identificadores separados y deben conservar sus frecuencias. No elimines filas originales simplemente porque coinciden sus mediciones.

El máximo original 58 aparece una sola vez; la probabilidad de que una réplica incluya 58 también es .648004. En consecuencia, la distribución del máximo bootstrap tiene una masa puntual grande en 58. El mismo cálculo que explica los duplicados normales señala una dificultad para inferir extremos no observados. Retomaremos esa dificultad con un argumento exacto de cobertura.

09Estimar el error estándar con réplicas

Sea θ̄* el promedio de las B estimaciones de réplica. El error estándar bootstrap es la desviación estándar muestral de esas estimaciones:

θ̄*=(1/B)Σb=1B θ̂*b; SEboot=√[Σb=1B(θ̂*b−θ̄*)²/(B−1)].

Resta el promedio de réplicas, eleva al cuadrado las desviaciones, suma, divide entre B−1 y toma la raíz. Es la operación de desviación estándar conocida en estadística descriptiva, aplicada ahora a estimaciones y no a mediciones de clientes. El denominador B−1 hace insesgada la varianza muestral de réplicas respecto de la varianza condicional cuando las réplicas son independientes y tienen varianza finita. Su raíz no tiene por qué ser insesgada. Para esta fórmula necesitamos B≥2.

No dividas SEboot entre √B para obtener la incertidumbre de la estimación poblacional original. SEboot ya mide dispersión entre estimaciones construidas con n observaciones. Dividir entre √B mide, en cambio, la incertidumbre numérica de promediar réplicas bootstrap. Son tareas diferentes. De lo contrario podríamos afirmar precisión arbitraria pulsando repetidamente el botón de simulación sin observar otro cliente.

La ejecución reproducible utiliza B=10000 y semilla 35026. Produce SE de la media≈3.795712 minutos y SE de la mediana≈3.787479 minutos. Su semejanza numérica en esta muestra no demuestra que media y mediana poblacionales tengan igual incertidumbre muestral. Proceden de estadísticos diferentes y pueden reaccionar de forma distinta a asimetría, empates y tamaño muestral.

Una primera comprobación son las unidades: el SE de una media de esperas debe expresarse en minutos. Otra es la escala: debe describir variación entre medias de réplicas, no reproducir la desviación mucho mayor entre esperas individuales. Una tercera es la generación independiente: reutilizar accidentalmente índices fijos produce estadísticos idénticos y un cero engañoso. Una semilla fija hace reproducible la secuencia; no debe reiniciarse el generador dentro de cada réplica.

10Derivar el SE condicional exacto de la media

Para la media, un cálculo exacto proporciona una referencia independiente de Monte Carlo. Trata los xi observados como números fijos. Una extracción X* selecciona cada fila con probabilidad 1/n. Su esperanza condicional es el promedio ponderado de todos los valores observados:

E*(X*)=Σi=1n xi(1/n)=x̄.

Su varianza condicional es el promedio empírico de desviaciones cuadradas vn=Σi=1n(xi−x̄)²/n=Q/n. Las n extracciones de una réplica son independientes condicionadas a los datos originales. La independencia anula las covarianzas: la varianza de la suma es n veces la de una extracción. Dividir la suma entre n divide su varianza entre n²:

Var*(X̄*)=Var*[(X*₁+⋯+X*n)/n]=(1/n²)×n×vn=vn/n=Q/n².

Con las esperas, Q=2058 y n²=144. Por tanto, Var*(X̄*)=2058/144=14.291666667 min² y SE*(X̄*)=√14.291666667≈3.780432 minutos. Además, E*(X̄*)=25 exactamente. Son propiedades exactas del modelo de remuestreo empírico, salvo el redondeo mostrado. El SE simulado 3.795712 difiere porque la ejecución usa un conjunto aleatorio finito de 10000 réplicas.

La estimación analítica convencional es s/√n=√[Q/(n(n−1))]≈3.948533. El cociente entre ambas es

SE*(X̄*)/(s/√n)=√[(n−1)/n]=√(11/12)≈.957427.

Aquí el SE condicional bootstrap es aproximadamente 4.26% menor incluso antes del error Monte Carlo. Es una diferencia de sustitución empírica en muestra finita; no demuestra que bootstrap obtuvo información adicional ni encontró un estimador superior. Al aumentar n, el cociente tiende a 1. Multiplicar el SE simulado por √[n/(n−1)] aproximaría esta referencia particular de varianza de la media, pero no calibraría automáticamente los extremos percentiles ni resolvería el problema bootstrap general.

11Sesgo, dispersión y corrección son distintos

El sesgo describe desplazamiento sistemático; el error estándar describe dispersión. El bootstrap estima el sesgo del estimador original tratando θ̂ como parámetro del mundo empírico y comparándolo con el promedio de estimaciones de réplica:

biasboot=θ̄*−θ̂.

Para la media, el sesgo condicional exacto es E*(X̄*)−x̄=0. La ejecución finita da promedio de réplicas 24.949675 y sesgo estimado−.050325 minutos. Ese pequeño valor no nulo refleja variabilidad Monte Carlo, porque sabemos que la esperanza condicional exacta es 25. No demuestra que la media muestral original quede sistemáticamente por debajo de la media poblacional real. Esa pregunta corresponde a EF(X̄)−μ, una esperanza diferente.

Para la mediana, el promedio de réplicas es 20.743850; por tanto, el sesgo estimado es 20.743850−20=.743850 minutos. Es una característica del modelo empírico ajustado y del estimador elegido, con incertidumbre adicional por B finito. Puede diagnosticar asimetría del procedimiento de estimación, pero no demuestra que la mediana verdadera sea 20−.743850. La distribución empírica también se estima con solo doce observaciones.

Una corrección directa sería θ̂bc=θ̂−biasboot=2θ̂−θ̄*. Para la mediana produce 19.256150 minutos en esta ejecución. La aritmética es válida; recomendarla como estimación mejor exige más. Corregir puede aumentar la varianza y el error cuadrático medio, especialmente si el sesgo se estima con ruido. Una estimación puntual corregida tampoco especifica un intervalo calibrado correspondiente.

Ahora existen tres centros distintos: la estimación original, el promedio bootstrap y el parámetro poblacional desconocido. Sepáralos en gráficos e informes. Que un intervalo sea asimétrico respecto de la estimación original no demuestra que haya corregido sesgo. Asimismo, cambiar la estimación puntual sin reconsiderar el método inferencial no justifica desplazar mecánicamente todos los extremos.

12Los cuantiles requieren una convención explícita

Un intervalo percentil utiliza cuantiles de los estadísticos de réplica. Para una distribución condicional ideal G*, definimos el cuantil de inversa acumulada como q*p=inf{t: G*(t)≥p}, con 0<p<1. En una distribución discreta es el primer valor del soporte cuya probabilidad acumulada alcanza p. Esta definición explica la importancia de empates y saltos. Puede no existir un corte que deje exactamente probabilidad p estrictamente por debajo.

Para una lista finita de B valores simulados, los programas suelen interpolar entre observaciones ordenadas. Nuestro código usa la convención lineal común denominada tipo 7. Ordena a₀≤a₁≤⋯≤aB−1, con índices desde cero. Calcula h=(B−1) p, j=floor(h) y g=h−j. Devuelve aj+g(aj+1−aj), recortando el índice superior a B−1 cuando se trata del extremo.

Para B=10000 y p=.025, h=9999×.025=249.975. Se utilizan los índices 249 y 250 con pesos .025 y .975 respectivamente. Si contamos posiciones desde uno, corresponden a las posiciones 250 y 251. Para p=.975, h=9749.025: se usan índices 9749 y 9750 con pesos .975 y .025. Declarar la convención de índices evita errores de una posición que pueden parecer discrepancias entre programas.

Como cálculo pequeño, toma valores de réplica ordenados [10,12,14,18,26]. Para p=.25, h=4×.25=1 y el cuantil es exactamente 12. Para p=.90, h=3.6 y el cuantil interpolado es 18+.6(26−18)=22.8. La interpolación puede producir un número ausente de la lista; es una convención numérica deliberada, no un resultado observado nuevo.

El cuantil exacto de inversa acumulada de una ley discreta y el cuantil interpolado de una lista finita no tienen por qué coincidir. Declara cuál calculaste. Con suficientes réplicas independientes suelen dar aproximaciones prácticas cercanas en cuantiles bien comportados, pero los saltos y la discreción exigen cuidado. Mostrar más decimales no elimina una diferencia de definiciones.

13Construir e interpretar un intervalo percentil

Para confianza nominal 1−α, el intervalo percentil bilateral toma los cuantiles α/2 y 1−α/2 de los estadísticos bootstrap. Para 95%, α=.05 y cada cola es .025:

CIpercentile=[q*.025, q*.975].

Utiliza los estadísticos, no los tiempos originales ni los índices ordenados de remuestreo. En nuestra ejecución finita, el intervalo de la media es [18.416667,33.000000] minutos. La estimación puntual es 25. La distancia inferior es 25−18.416667=6.583333 y la superior 33−25=8 minutos. El intervalo es asimétrico por la distribución condicional y los cuantiles elegidos. No lo sustituyas por uno simétrico manteniendo la misma etiqueta.

La interpretación frecuentista pretendida corresponde al procedimiento que genera intervalos entre muestras originales nuevas. Bajo condiciones que hagan fiable este método bootstrap, aproximadamente 95% de esos intervalos contendrían la media poblacional fija. El intervalo particular no afirma que μ tenga ahora probabilidad 95% de caer entre sus extremos. Tampoco afirma que 95% de los clientes individuales esperan entre 18.42 y 33 minutos.

Sobre todo, encerrar la parte central de una distribución bootstrap no demuestra cobertura poblacional 95%. La ley bootstrap estima una ley muestral; además, la transformación percentil debe ser apropiada. Sesgo en muestras pequeñas, asimetría, fronteras y estadísticos inadecuados pueden perjudicar la cobertura. En este pequeño caso construido, los extremos enseñan el método y describen la aproximación calculada; no certifican inferencia de servicio calibrada al 95%.

El método percentil atrae porque su construcción es transparente y sus extremos respetan el soporte del estadístico de réplica. No es una elección universal para análisis de consecuencias importantes. La justificación teórica, los diagnósticos, otros métodos y suficientes datos originales siguen formando parte de elegir un intervalo. Un intervalo estrecho no demuestra calidad si su cobertura es deficiente.

16Separar error de simulación e incertidumbre muestral

Existen dos fuentes de aproximación. Primero, Fn estima F mediante n observaciones originales. Segundo, B réplicas aleatorias aproximan características de la ley condicional bajo Fn. Aumentar B atiende la segunda fuente. No cambia los datos originales, la estimación puntual, la distribución empírica ni la información poblacional ausente. Aumentar n con observaciones nuevas válidas puede mejorar la primera aproximación, aunque siguen importando diseño y distribución.

17Conservar pares cuando la unidad es una persona

Supón que cuatro personas independientes tienen mediciones antes y después, en unidades comunes arbitrarias: (1,2),(2,3),(3,4),(4,5). El objetivo es el cambio medio poblacional dentro de cada persona E(Y−X). Lo estimamos promediando las cuatro diferencias observadas. Todas valen 1 y el cambio medio estimado es 1. Como X e Y pertenecen a la misma persona, una unidad remuestreada es el par completo.

Un bootstrap pareado extrae cuatro identificadores de persona con reemplazo y conserva ambas mediciones de cada persona seleccionada. Para este estadístico equivale a calcular primero las cuatro diferencias y remuestrearlas. Todas las diferencias de réplica siguen siendo 1 y el SE bootstrap condicional es 0 en este conjunto construido. Ese cero describe una distribución empírica degenerada de los cambios observados. No demuestra que todos los cambios poblacionales sean 1 ni que cuatro personas establezcan certeza poblacional perfecta.

Ahora remuestrea X e Y independientemente. Esa operación crea emparejamientos artificiales y destruye la covarianza observada. Las varianzas empíricas de X e Y son 1.25 cada una y su covarianza empírica es 1.25. Con extracciones pareadas,

Var*(cambio medio)=[1.25+1.25−2(1.25)]/4=0.

Con columnas independientes, la covarianza se vuelve 0: la varianza pasa a(1.25+1.25)/4=.625 y el SE a √.625≈.790569. La discrepancia procede de otro experimento, no de ruido Monte Carlo. Remuestrear columnas independientemente podría corresponder a un diseño distinto de grupos independientes, no a estos registros emparejados.

18Las filas no siempre son unidades independientes

Considera cuatro sucursales independientes con tres mediciones cada una: A tiene [2,2,2], B [4,4,4], C [6,6,6] y D [8,8,8]. Los valores idénticos dentro de sucursal exageran deliberadamente la dependencia para calcular exactamente su efecto. La media global observada es 5. Como los tamaños son iguales, promediar las cuatro medias de sucursal equivale a promediar las doce filas.

Un bootstrap de grupos completos selecciona cuatro identificadores de sucursal con reemplazo y conserva las tres mediciones de cada sucursal elegida. La distribución empírica de medias [2,4,6,8] tiene varianza 5. La varianza condicional de su media remuestreada es 5/4=1.25 y el SE≈1.118034. Seleccionar otra vez una sucursal significa transportar de nuevo todo su grupo, no observar sucursales nuevas independientes.

El bootstrap incorrecto de filas independientes trata los doce valores como extracciones iid. Su varianza empírica también es 5, pero la media simulada promedia ahora doce extracciones independientes. Su varianza condicional es 5/12 y su SE≈.645497. El cociente entre el SE por grupos del ejemplo y el SE por filas es √3. El método por filas reduce la dispersión porque inventa independencia entre mediciones que se mueven juntas.

Cuatro grupos siguen aportando información independiente muy limitada. Muchas filas dentro de ellos no compensan automáticamente esa limitación. Con tamaños desiguales importa el objetivo: una media entre personas y una media con igual peso por sucursal pueden diferir. Remuestrear grupos y recalcular una razón de totales puede generar cantidades variables de filas; eso no es automáticamente un error. Especifica pesos, población objetivo y diseño antes de elegir el algoritmo.

Para visitas repetidas, remuestrea pacientes independientes y conserva sus historiales cuando corresponda al diseño. En encuestas complejas, estratos, pesos, unidades primarias y fracciones finitas pueden requerir métodos específicos de réplicas. No existe una orden universal de remuestrear filas que conserve cualquier diseño. La unidad correcta es una propiedad científica del proceso generador, no una propiedad de la disposición de la hoja de cálculo.

19Orden temporal y procedimiento completo de análisis

En una serie temporal, observaciones vecinas pueden compartir perturbaciones o persistencia. Remuestrear instantes individuales independientemente sustituye esa dependencia por independencia. La distribución resultante puede subestimar o distorsionar la incertidumbre de medias, tendencias y pronósticos. Una serie larga no justifica ignorar estructura temporal si la información independiente efectiva es mucho menor que el número de filas.

Un bootstrap por bloques extrae tramos consecutivos y conserva la adyacencia local dentro de cada tramo seleccionado. En [2,3,4,8,9,10], por ejemplo, los bloques solapados de longitud 3 son [2,3,4], [3,4,8], [4,8,9] y [8,9,10]. Seleccionar [8,9,10] y [2,3,4] produce seis entradas que mantienen el orden interno de cada bloque. Es una ilustración mecánica, no un diseño inferencial recomendado para una serie de seis puntos.

La longitud de bloque equilibra conservar dependencia y disponer de suficientes bloques variables. Importan estacionariedad u otra estructura temporal justificada, tratamiento de tendencia y estacionalidad, y estadístico objetivo. Las fronteras entre bloques pueden romper dependencia; remuestrear condiciones antiguas puede ser inadecuado después de un cambio estructural. El currículo desarrollará después métodos temporales y de supervivencia; aquí el límite consiste en reconocer por qué no puede trasladarse sin cambios el bootstrap iid ordinario.

También importa el procedimiento completo de estimación. Si preprocesamiento, imputación o ajuste forman parte del estimador cuya incertidumbre interesa, generalmente deben repetirse los pasos apropiados dentro de cada réplica. Mantener fijo un componente ajustado estima una cantidad condicional que podría omitir incertidumbre. En cambio, cambiar el objetivo científico entre repeticiones produce una mezcla difícil de interpretar.

Para predicción, incertidumbre de parámetros ajustados, incertidumbre de respuesta media y variabilidad de un resultado individual nuevo son diferentes. Remuestrear entrenamiento y examinar medias ajustadas no produce automáticamente un intervalo predictivo individual. Evita fuga de información al evaluar desempeño. Estas distinciones conectan el remuestreo con trabajo aplicado sin exigir prematuramente un catálogo de algoritmos avanzados.

20Un fallo preciso: estimar un extremo no observado

Sean las observaciones reales iid Uniform(0,θ), con θ>0 como extremo superior poblacional desconocido. Estimamos θ mediante el máximo muestral M. Con un número finito de extracciones de una distribución continua, M<θ con probabilidad 1. Una réplica no paramétrica solo utiliza valores observados: todo máximo bootstrap M* cumple M*≤M. En consecuencia, cualquier percentil de esos máximos es menor o igual que M.

Considera cualquier intervalo percentil bilateral ordinario para θ construido directamente con esos máximos. Su extremo superior U* cumple U*≤M<θ casi seguramente. Por ello θ no puede pertenecer al intervalo, cualquiera que sea su extremo inferior:

Pθ(θ∈CIpercentile del máximo sin modificar)=0.

La cobertura es cero, no una pequeña reducción respecto de 95%. Ocurre para todo n original finito y cualquier B mientras los extremos sean cuantiles de los máximos sin modificar. Aumentar B estima con más fidelidad una ley condicional de forma inadecuada. No puede generar un valor observado superior a M ni hacer que esta construcción percentil alcance θ.

Cuando el máximo muestral es único, P*(M*=M)=1−(1−1/n)n. Para n=12 es aproximadamente .648004: una masa puntual grande en la frontera observada. En cambio, el máximo de una muestra nueva de población continua varía por debajo de θ sin asignar masa puntual al M previamente observado. Esta discrepancia estructural ayuda a explicar el fallo.

La conclusión se refiere al bootstrap percentil ingenuo del máximo sin modificar para estimar el extremo de una Uniforme. No afirma que falle todo método bootstrap para cualquier parámetro acotado. Otros modelos, estadísticos, pivotes o esquemas especializados podrían permitir inferencia válida del extremo. La respuesta es utilizar un método justificado para el problema de frontera, no ocultar la restricción superior mediante una densidad suavizada.

En las esperas, el máximo 58 es simplemente la mayor espera observada, no una cota física poblacional. El bootstrap ingenuo no descubre esperas raras de 70 minutos ausentes de la muestra. Estimar un cuantil alto o una probabilidad de cola del servicio requiere especial atención a la información original de cola, aunque el bootstrap de la media parezca razonable.

21Condiciones y señales de advertencia

El bootstrap empírico ordinario suele partir de unidades independientes e idénticamente distribuidas de la población pertinente al estimando. Esa formulación contiene varios requisitos. La independencia corresponde a las unidades; la distribución idéntica, a condiciones generadoras comparables; la pertinencia, a la conexión entre unidades seleccionadas y objetivo. Una muestra voluntaria de clientes fáciles de contactar puede incumplir pertinencia aunque sus filas sean independientes.

También importa la regularidad estadística. Para una media iid, la varianza poblacional finita respalda la aproximación convencional de muestra grande. Colas pesadas con varianza inestable o infinita pueden invalidar el razonamiento ordinario sobre SE. Para una mediana importa el comportamiento cerca del cuantil objetivo. Estimadores en fronteras y estadísticos extremos o poco regulares pueden requerir análisis especializado. La distribución empírica aproxima frecuencias observadas, pero no toda función de ella hereda una buena aproximación muestral.

Examina datos y diseño antes de simular. Busca observaciones influyentes, muchos empates, faltantes, eventos raros, condiciones cambiantes y grupos o tiempos que compartan una fuente. Un conteo observado de cero asigna probabilidad empírica 0 al evento. El remuestreo no paramétrico produce entonces cero eventos en todas las réplicas, aunque la probabilidad real sea positiva. Un intervalo bootstrap de ancho cero puede señalar falta de información, no alta precisión.

22Bootstrap y permutación responden preguntas distintas

Un bootstrap para estimación remuestrea desde una distribución de datos ajustada, normalmente con reemplazo, para aproximar incertidumbre de un estimador. Una prueba de permutación reordena etiquetas u otros componentes intercambiables bajo una hipótesis nula especificada, normalmente sin reemplazo. Su validez depende del diseño de aleatorización o de la intercambiabilidad justificada por la hipótesis nula. Las palabras aleatorio y simulación no hacen intercambiables ambos procedimientos.

Para una media de una muestra, barajar los doce valores conserva la media; no estima su SE muestral. En dos grupos de tratamiento aleatorizados, en cambio, reasignar resultados observados fijos a etiquetas bajo una hipótesis nula precisa apropiada puede generar una distribución de referencia útil del contraste. El estadístico y el experimento nulo difieren de nuestro bootstrap de una muestra.

from random import Random
from statistics import mean, median, stdev
from math import sqrt

n, B = len(x), 10000
rng = Random(35026)

def quantile(values, p):
    a = sorted(values)
    h = (len(a) - 1) * p
    j = int(h)
    return a[j] + (h - j) * (a[min(j + 1, len(a) - 1)] - a[j])

means, medians = [], []
for b in range(B):
    indices = [rng.randrange(n) for j in range(n)]
    sample = [x[j] for j in indices]
    means.append(mean(sample))
    medians.append(median(sample))

qsum = sum((v - mean(x)) ** 2 for v in x)
print(f"n={n}; B={B}; sum={sum(x)}; Q={qsum:.6f}")
print(f"mean={mean(x):.6f}; median={median(x):.6f}")
print(f"exact conditional mean SE={sqrt(qsum) / n:.6f}")
print(f"analytic mean SE={stdev(x) / sqrt(n):.6f}")
for name, original, reps in [("mean", mean(x), means),
                              ("median", median(x), medians)]:
    lo, hi = quantile(reps, .025), quantile(reps, .975)
    print(f"{name}: SE={stdev(reps):.6f}; bias={mean(reps)-original:.6f}")
    print(f"{name}: percentile95=[{lo:.6f}, {hi:.6f}]")
print(f"MCSE of bootstrap mean={stdev(means)/sqrt(B):.6f}")
