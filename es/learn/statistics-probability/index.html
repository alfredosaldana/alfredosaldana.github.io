Statistics & Probability

Una ruta estructurada para construir desde los fundamentos el razonamiento probabilístico y estadístico necesario para comprender datos, incertidumbre, inferencia y modelado.

Recursos → Statistics & Probability

De la incertidumbre a la inferencia estadística.

Esta ruta comienza con Probability desde los fundamentos y avanza de forma gradual hacia Random Variables, distributions, sampling, estimación, Confidence Intervals, Hypothesis Testing y comparación de grupos.

La parte final conecta estos fundamentos con Chi-Square Tests, Correlation y Simple Linear Regression, permitiendo entender no solo cómo calcular resultados, sino también qué significan y bajo qué supuestos deben interpretarse.

Orden de aprendizaje recomendado: sigue las guías en secuencia. Cada bloque introduce conceptos que serán utilizados directamente en los temas siguientes.
Guías

Secuencia de aprendizaje

La ruta sigue una progresión intencional: Probability → Random Variables → Distributions → Population vs. Sample → Sampling Distributions → Central Limit Theorem → Standard Error → Confidence Intervals → Hypothesis Testing → t-tests → F-test → ANOVA → Chi-Square → Correlation → Regression.

¿Por qué este orden?

Primero necesitamos entender cómo describir incertidumbre con Probability y Random Variables. Después estudiamos distributions porque proporcionan modelos matemáticos para distintos tipos de resultados aleatorios.

Luego pasamos de una sola variable aleatoria a la idea de muestrear repetidamente una población. Allí aparecen Sampling Distributions, Central Limit Theorem, Standard Error y Confidence Intervals.

Con esa base, Hypothesis Testing, t-tests, F-tests, ANOVA y Chi-Square dejan de ser procedimientos aislados: se convierten en aplicaciones de una misma lógica inferencial. Finalmente, Correlation y Simple Linear Regression conectan la inferencia con relaciones entre variables.
