Deep Learning

Una ruta estructurada para comprender Neural Networks desde tensors y neurons hasta CNNs, RNNs, Attention, Transformers y PyTorch.

Recursos → Deep Learning

De tensors y neurons a Transformers.

Esta ruta comienza con Tensors y las operaciones fundamentales en PyTorch, y después construye Neural Networks desde el Artificial Neuron, Activation Functions y Forward Propagation.

Luego desarrollamos Loss Functions, Backpropagation, Chain Rule, optimizers, regularization y normalization antes de estudiar CNNs, RNNs, LSTM, GRU, Attention y Transformers.

Orden de aprendizaje recomendado: sigue las guías en secuencia. La ruta está diseñada para que la matemática, la intuición y la implementación se construyan juntas.
Guías

Secuencia de aprendizaje

El recorrido sigue una progresión intencional: Tensors → Neural Networks → Forward Propagation → Loss → Backpropagation → Optimization → CNNs → RNNs/LSTM/GRU → Attention → Transformers → PyTorch → Deployment.

Guía visual: azul = tensors y fundamentos de redes, verde = aprendizaje y optimización, violeta = estabilidad y regularization, naranja = arquitecturas modernas, rojo = implementación y lifecycle.

¿Por qué este orden?

Primero necesitamos comprender la estructura de los datos y el cálculo básico dentro de una red: tensors, neurons, layers, activations y Forward Propagation.

Después introducimos Loss Functions, Backpropagation y optimizers porque explican cómo aprende realmente una red. Weight Initialization, gradient stability, regularization y normalization ayudan a entender por qué entrenar redes profundas puede ser difícil.

Con esa base, CNNs y RNNs pueden estudiarse como arquitecturas diseñadas para diferentes estructuras de datos. Attention y Transformers amplían estas ideas, y finalmente PyTorch y deployment conectan la teoría con un workflow real de Deep Learning.
