Bank Customer Churn Prediction

An end-to-end classification project exploring which customers are most likely to leave and which variables contribute to churn.

Completed

Project question

Can customer attributes be used to identify elevated churn risk and compare the behavior of multiple classification models?

Approach

The project includes exploratory data analysis, preprocessing, class balancing, model training and evaluation across multiple classification methods.

Methods represented in the project

  • Logistic Regression
  • Decision Trees
  • Random Forest
  • Support Vector Classifier
  • Gradient Boosting
  • K-Nearest Neighbors

The website description is intentionally concise; the repository should remain the source of truth for the exact current implementation.
