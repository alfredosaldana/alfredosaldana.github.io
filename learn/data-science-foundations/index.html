Data Science Foundations

A structured learning path for understanding the core ideas that connect data, predictions, model evaluation, and reliable model performance.

Learn → Data Science Foundations

Build the ideas that make model results meaningful.

Before studying many algorithms, we need to understand clearly what a prediction is, how predictions become classes, how model errors are counted, what questions each metric answers, and how to evaluate a model reliably.

This learning path moves from the basic language of supervised learning to Confusion Matrices, evaluation metrics, class imbalance, thresholds, ROC-AUC, calibration, data splitting, data leakage, generalization, and baseline models.

Recommended learning order: start with the first guides and follow the sequence. Each topic builds the language and intuition needed to understand the next one.
Guides

Learning sequence

The order is intentional: we begin with data and predictions, continue with metrics, then move into threshold-based evaluation, and finally reach reliable model validation.

Why this order?

The sequence begins with the basic language of datasets and predictions. Once those ideas are clear, it becomes natural to learn how predictions become classes, how the Confusion Matrix is built, and how Accuracy, Precision, Recall, and related metrics are derived.

After that foundation, the path moves into more advanced evaluation concepts: class imbalance, thresholds, ROC-AUC, Precision–Recall curves, and calibration. Finally, it concludes with validation, data leakage, generalization, baseline models, and metric selection—essential concepts for evaluating models reliably in real-world problems.
