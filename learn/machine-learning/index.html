Machine Learning

Una ruta estructurada desde los fundamentos de Machine Learning hasta ensembles, tuning, explainability y deployment.

Aprender → Machine Learning

Aprende cómo funcionan los modelos, no solamente cómo ejecutarlos.

Machine Learning no consiste únicamente en importar un algoritmo y llamar fit(). Para trabajar con modelos de manera sólida necesitamos comprender qué problema estamos resolviendo, cómo se prepara la información, cómo aprende cada familia de modelos y cómo se compara una solución con otra.

Esta ruta comienza con la formulación del problema y el workflow completo, continúa con modelos lineales, preparación de features, árboles y ensembles, y termina con tuning, explainability, pipelines y el ciclo de vida del modelo.

Orden recomendado: sigue la secuencia desde los fundamentos. Los nombres de modelos, métodos y conceptos técnicos se mantienen en inglés para conservar la terminología utilizada en libros, papers, documentación y cursos de Machine Learning.

¿Por qué este orden?

Primero definimos qué significa Machine Learning y qué tipo de problema estamos resolviendo. Después estudiamos el workflow completo para que cada algoritmo aparezca dentro de un proceso y no como una técnica aislada.

Luego avanzamos desde Linear Regression y Logistic Regression hacia Loss Functions, Gradient Descent y Regularization. Con esa base, entramos a Feature Engineering, preprocessing, Decision Trees, Random Forest, Bagging, Boosting y XGBoost.

Finalmente, la ruta aborda Hyperparameter Tuning, Model Selection, Feature Importance, SHAP, Class Imbalance, reproducible Pipelines y el paso de un notebook a un modelo desplegado y monitoreado.
