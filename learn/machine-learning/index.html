Learn · Machine Learning

Machine Learning

A structured learning path from Machine Learning foundations to ensembles, tuning, explainability, and deployment.

Learn → Machine Learning

Learn how models work, not only how to run them.

Machine Learning is not just about importing an algorithm and calling fit(). To work with models rigorously, we need to understand what problem we are solving, how information is prepared, how each family of models learns, and how one solution should be compared with another.

This path begins with problem formulation and the complete Machine Learning workflow, continues through linear models, feature preparation, trees and ensembles, and ends with tuning, explainability, pipelines, and the model lifecycle.

Recommended order: follow the sequence from the foundations. Each topic is designed to build directly on ideas introduced earlier.

Why this order?

We first define what Machine Learning means and what kind of problem we are solving. We then study the complete workflow so that every algorithm appears within a process rather than as an isolated technique.

Next, we move from Linear Regression and Logistic Regression to Loss Functions, Gradient Descent, and Regularization. With that foundation, we introduce Feature Engineering, preprocessing, Decision Trees, Random Forest, Bagging, Boosting, and XGBoost.

Finally, the path covers Hyperparameter Tuning, Model Selection, Feature Importance, SHAP, Class Imbalance, reproducible Pipelines, and the transition from a notebook to a deployed and monitored model.
