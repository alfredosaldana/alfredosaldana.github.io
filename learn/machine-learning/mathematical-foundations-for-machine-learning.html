1. Mathematics is the language of learning from data

A technician notices that some industrial machines develop abnormal vibration before they fail. Can a model combine sensor measurements to help prioritize inspections? This chapter follows that question through the mathematical foundations that appear repeatedly in Machine Learning (ML). We will not pretend that six measurements are sufficient to deploy a reliable safety system; the dataset is intentionally small so that every number is inspectable.

A model takes numerical inputs, combines them through mathematical operations, produces a prediction, and adjusts learned parameters when appropriate. These four activities connect four areas: Linear Algebra represents information, Calculus describes change and optimization, Probability and Statistics quantify uncertainty, and Geometry explains similarity and distance. Their roles overlap rather than existing as separate, disconnected chapters.

The complete illustrative dataset

Machine Temperature (°C) Vibration (mm/s) Failure in next 30 days (y)
A 60 2 0
B 70 3 1
C 65 4 0
D 80 6 1
E 75 5 0
F 85 7 1

The observation is one machine at a specified snapshot. Its Features are temperature and vibration available then; its Target is whether failure occurs during the following 30 days (1 = yes, 0 = no). The labels are invented, not measured outcomes. Machine B fails despite a moderate reading, while E does not fail despite elevated readings: even a simple example should discourage the idea that one threshold explains every event.

Our learning thread. We will represent machine A as a vector; combine Features using a Dot Product; evaluate a hypothetical probability model; calculate a gradient update; and use the observed labels to illustrate Conditional Probability and diagnostic errors. Advanced modeling is intentionally left for later chapters.

By the end, you should be able to trace the units and dimensions of a formula, reproduce elementary vector and matrix arithmetic, interpret a derivative and a gradient, apply Bayes' Theorem, and explain why an illustrative calculation is not evidence of a production-ready prediction model.

2. Scalars, variables, units, and mathematical notation

A scalar is one number, such as 60°C or the binary label 0. A Feature is a measured characteristic; a variable describes its possible values. A parameter is a quantity a model uses to turn Features into an output. These ideas must stay distinct: temperature is input data, a coefficient multiplying temperature is a parameter, and a predicted probability is an output.

Percent, percentage points, and unit conversion

Suppose a vibration sensor rises from 2 to 3 mm/s. The absolute change is 1 mm/s and the relative increase is \((3-2)/2\times100=50\%\). If an estimated failure rate moves from 10% to 15%, the absolute difference is 5 percentage points, while the relative increase is \((15-10)/10=50\%\). Confusing these descriptions can turn a correct calculation into a misleading report.

Numbers cannot be added meaningfully just because they both appear in a spreadsheet. The expression \(60+2=62\) is arithmetically valid, but adding °C to mm/s has no physically meaningful interpretation. Weighted sums can be useful because their coefficients compensate for units or because variables have been appropriately transformed. We should always ask what units a coefficient must carry to make the final result coherent.

Indices, symbols, and a row of data

Let \(i\) identify a machine, \(x_{i1}\) its temperature, \(x_{i2}\) its vibration, and \(y_i\) its observed failure label. Then machine C has \(x_{31}=65\), \(x_{32}=4\), and \(y_3=0\). The number 3 in the subscript is a row index, not an exponent; \(x_{31}^2=65^2\) would instead square the measurement.

\[x_{i1}=\text{temperature},\qquad x_{i2}=\text{vibration},\qquad y_i\in\{0,1\}\]

The symbol \(\in\) means “belongs to”; braces denote a set of allowed values. Later, \(\hat y\) denotes a prediction, not an observed label, and \(\theta\) denotes a group of parameters. Defining symbols before manipulating them prevents students from mixing data, predictions, and model configuration.

Common misunderstanding. A Feature recorded as 0.75 might represent a proportion (75%) or a percentage value (0.75%). A model comparing a proportion of 0.75 with a threshold of 50 intended for a 0–100 percentage scale will produce the wrong decision even if the program runs without an error.

3. Vectors: representing one observation and measuring distance

A vector is an ordered collection of numbers. We can express machine A's two sensor readings as a column vector. The first entry must always mean temperature and the second vibration; silently reversing that order changes the computation.

\[\mathbf{x}_A=\begin{bmatrix}60\\2\end{bmatrix},\qquad \mathbf{x}_D=\begin{bmatrix}80\\6\end{bmatrix}\]

These vectors live in \(\mathbb{R}^2\), the two-dimensional space of real-valued coordinates. Their difference is computed position by position: \(\mathbf{x}_D-\mathbf{x}_A=[20,4]^T\). Multiplying a vector by 2 also multiplies every coordinate: \(2\mathbf{x}_A=[120,4]^T\). That operation is mathematical, not a claim that a real machine can double its physical temperature without changing other conditions.

Norms and Euclidean distance

The Euclidean norm measures a vector's length; the Euclidean distance measures the length of a difference. If we temporarily ignore incompatible measurement units, the raw numerical separation of A and D is:

\[\|\mathbf{x}_D-\mathbf{x}_A\|_2=\sqrt{(80-60)^2+(6-2)^2}=\sqrt{416}\approx20.396\]

Here the subscript 2 indicates the Euclidean (L2) norm, not that we square the entire answer. This raw distance is not a physically interpretable distance in one unit, since it combines °C and mm/s; it is the numerical result of a chosen coordinate representation. The temperature difference of 20 dominates the vibration difference of 4.

A second common distance is Manhattan (L1) distance, the sum of absolute coordinate differences: \(|80-60|+|6-2|=24\), again only a coordinate-based score until units are handled. Distance-based methods such as k-Nearest Neighbors and k-Means depend on this choice.

Interpretation. “Nearby machines” has no objective meaning until we define relevant Features, their scales and a distance metric. A model that groups sensors by similarity could change its group assignments after sensible rescaling even though no machine measurements changed.

Geometry and direction, beyond raw length

Two vectors can have similar directions but different lengths. The Dot Product connects direction and length through \(\mathbf{a}^T\mathbf{b}=\|\mathbf{a}\|_2\|\mathbf{b}\|_2\cos\phi\), where \(\phi\) is the angle between them. For example, unit vectors \([1,0]^T\) and \([0,1]^T\) have Dot Product zero and are perpendicular; \([1,0]^T\) and \([1,0]^T\) have Dot Product one and point in the same direction. Cosine Similarity divides by both vector lengths and is undefined for a zero vector. These ideas help explain text-embedding similarity and other representation methods, but ordinary sensor Features with incompatible units still require careful interpretation before geometric similarity is meaningful.

4. Dot Products: turning several Features into one score

A Dot Product multiplies matching vector entries and adds the products. For two two-component vectors \(\mathbf{a}=[a_1,a_2]^T\) and \(\mathbf{b}=[b_1,b_2]^T\), it is a scalar:

\[\mathbf{a}^T\mathbf{b}=a_1b_1+a_2b_2\]

The superscript \(T\) means Transpose: writing a column vector as a row. Consider hypothetical weights \(w_T=0.04\) per °C and \(w_V=0.30\) per mm/s, together with an intercept \(b=-4\). The resulting linear score is

\[z=b+\mathbf{w}^T\mathbf{x}=-4+0.04\,T+0.30\,V.\]

For machine A, substitute both measurements rather than jumping to the result:

\[z_A=-4+(0.04\times60)+(0.30\times2)=-4+2.40+0.60=-1.00\]

For machine F: \(z_F=-4+(0.04\times85)+(0.30\times7)=-4+3.40+2.10=1.50\). The weights and intercept were chosen for instruction; no training algorithm estimated them. Since \(z\) is a dimensionless score in this example, the coefficient multiplying °C has reciprocal-°C units and the vibration coefficient reciprocal-(mm/s) units.

Why does the Dot Product matter?

The same pattern appears in Linear Regression, Logistic Regression and individual Neural Network units. Multiple inputs contribute through learned weights. The weight sign indicates the local direction of that term: holding vibration fixed, a higher temperature adds to our hypothetical score because its coefficient is positive. That is an association built into a score, not proof that raising the temperature causes a failure.

A score is not automatically a probability. Here \(z_A=-1\) and \(z_F=1.5\) are not numbers between 0 and 1. A suitable transformation, such as the Sigmoid Function, can turn a real-valued score into a number in (0,1), which we will examine later.

Sanity check. If the vibration value for A increased by exactly 1 mm/s while temperature stayed fixed, its score would increase by \(0.30\). If temperature increased by 1°C instead, the score would increase by \(0.04\). These are changes in the score under fixed weights—not yet changes in a calibrated failure probability.

Decompose a change into Feature contributions

Compare machines A and D: their temperature rises by 20°C and vibration rises by 4 mm/s. Since the intercept cancels when subtracting scores, \(z_D-z_A=0.04(80-60)+0.30(6-2)=0.80+1.20=2.00\). We can verify independently that \(z_D=1\) and \(z_A=-1\), so the difference is also \(1-(-1)=2\). The 0.80 and 1.20 components are a valid additive decomposition of this chosen linear score. They are not estimates of each sensor's causal effect and should not be automatically described as economic or physical contributions to actual breakdown risk.

5. Matrices: representing an entire dataset without losing its meaning

A matrix is a rectangular arrangement of numbers. With six machines and two sensor Features, the Feature Matrix has six rows and two columns. Standard notation places observations in rows and Features in columns:

\[X=\begin{bmatrix}60&2\\70&3\\65&4\\80&6\\75&5\\85&7\end{bmatrix}\in\mathbb{R}^{6\times2},\qquad \mathbf{y}=\begin{bmatrix}0\\1\\0\\1\\0\\1\end{bmatrix}\in\mathbb{R}^{6}.\]

Dimensions are a contract. \(X\) has shape 6×2; its rows correspond to A–F in that order. The labels form a six-component vector. Transposing the matrix yields \(X^T\in\mathbb{R}^{2\times6}\): the six temperatures now occupy one row and the six vibrations another. A transpose rearranges axes; it does not alter measured values.

Adding the intercept column

Our score contains \(b\), a constant not tied to either sensor. We can absorb it into a Design Matrix by prepending a column of ones:

\[\widetilde X=\begin{bmatrix}1&60&2\\1&70&3\\1&65&4\\1&80&6\\1&75&5\\1&85&7\end{bmatrix},\quad \boldsymbol\theta=\begin{bmatrix}-4\\0.04\\0.30\end{bmatrix}.\]

The new shapes are 6×3 and 3×1, so their matrix product \(\widetilde X\boldsymbol\theta\) is a 6×1 vector of scores. The first row yields \(1(-4)+60(0.04)+2(0.30)=-1\). More generally, the number of columns on the left must equal the number of rows on the right for ordinary matrix multiplication.

Notice what this representation does not say. The six labels do not become known at prediction time; they are used later for training or evaluation. We display them next to the Features to teach the mathematics, while a real pipeline must prevent future Labels from leaking into current inputs.

Shape does not equal meaning

Suppose a new dataset has 200 rows and three sensor columns. Its shape would be 200×3, but this number alone does not specify whether the third column means pressure, operating hours, or an accidental duplicate label. We need a Feature Schema that gives a name, unit, timestamp and ordering rule to each column. If we add an intercept, the associated Design Matrix becomes 200×4 and the parameter vector must contain four entries. A shape check protects arithmetic; a schema check protects interpretation. Both are necessary for reproducible Machine Learning.

6. Matrix multiplication, linear transformations, and shape checking

Matrix multiplication is not elementwise multiplication. For matrices \(A\in\mathbb{R}^{m\times n}\) and \(B\in\mathbb{R}^{n\times p}\), their product \(AB\) has shape \(m\times p\). Each output entry is a Dot Product of one row of A and one column of B.

A small calculation you can reproduce

Let \(A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\) and \(B=\begin{bmatrix}2&0\\1&5\end{bmatrix}\). Compute all four entries explicitly:

\[AB=\begin{bmatrix}1(2)+2(1)&1(0)+2(5)\\3(2)+4(1)&3(0)+4(5)\end{bmatrix}=\begin{bmatrix}4&10\\10&20\end{bmatrix}.\]

Reversing the order gives \(BA=\begin{bmatrix}2&4\\16&22\end{bmatrix}\), which differs from \(AB\). In general, \(AB\ne BA\). That fact is essential when reasoning about successive transformations or the order of operations in a model.

Transforming all machine readings at once

Use \(\widetilde X\boldsymbol\theta\) from Section 5. The complete score vector is

\[\mathbf{z}=\widetilde X\boldsymbol\theta=\begin{bmatrix}-1.00\\-0.30\\-0.20\\1.00\\0.50\\1.50\end{bmatrix}.\]

Verify the third entry: \(-4+65(0.04)+4(0.30)=-4+2.6+1.2=-0.2\). The matrix expression calculates all six examples through the same rule. In software, a mismatch between two shapes should be treated as a modeling or data-specification error rather than “solved” by reshaping arrays arbitrarily until a calculation runs.

Linear transformations map vectors into other vector spaces through matrix multiplication. Adding an intercept makes the complete map affine, not strictly linear in the mathematical sense. This distinction becomes important when we study the geometry of decision boundaries and Neural Networks.

Connection to computation. NumPy computes the batch of six scores using matrix multiplication; we still need to understand why the Feature order is fixed and why a parameter vector must have the right length. The mathematical representation makes those requirements visible.

When two columns contain different information

A useful elementary algebraic test is the Determinant of a square 2×2 matrix. Form a two-row matrix from machines A and B, with rows \([60,2]\) and \([70,3]\). Its determinant is \(60(3)-70(2)=180-140=40\), which is nonzero. Thus the two column vectors in this 2×2 example are linearly independent; one is not an exact constant multiple of the other. This does not prove the Features are statistically uncorrelated—Section 8 finds substantial Correlation. Linear dependence is an exact algebraic property; Correlation measures a graded statistical relationship. Larger matrices require rank-based reasoning rather than a determinant for a nonsquare array.

Multiply rectangular matrices: trace every output entry

To see why shapes mean more than a rule to memorize, take these abstract (dimensionless) matrices:

\[A=\begin{bmatrix}1&2&0\\0&1&3\end{bmatrix}\in\mathbb R^{2\times3},\qquad B=\begin{bmatrix}2&1\\1&0\\0&2\end{bmatrix}\in\mathbb R^{3\times2}.\]

The inner dimensions match (3 and 3). The top-left output uses the first row against the first column: \(1(2)+2(1)+0(0)=4\). Carry out the other three products just as explicitly:

\[AB=\begin{bmatrix}1(2)+2(1)+0(0)&1(1)+2(0)+0(2)\\0(2)+1(1)+3(0)&0(1)+1(0)+3(2)\end{bmatrix}=\begin{bmatrix}4&1\\1&6\end{bmatrix}.\]

The resulting shape is 2×2, corresponding to two output rows and two columns. Attempting \(AA\) is undefined because the inner dimensions would be 3 and 2. Shape checks prevent a program from performing a calculation that has no well-defined mathematical meaning.

7. Feature Scaling, norms, and why “similar” depends on measurement units

Section 3 showed that raw Euclidean distance mixes temperature and vibration on incompatible numerical scales. Feature Scaling changes the coordinate representation so different Features have more comparable influence when the method uses distances, penalized coefficients, or numerical optimization.

A simple educational scaling divides a temperature difference by 10°C and a vibration difference by 2 mm/s. The differences between machines A and B are 10°C and 1 mm/s, so the scaled difference vector is \([10/10,\ 1/2]=[1,0.5]\). The Euclidean distance becomes

\[d_{AB,\mathrm{scaled}}=\sqrt{1^2+0.5^2}=\sqrt{1.25}\approx1.118.\]

The raw numerical distance would have been \(\sqrt{10^2+1^2}=\sqrt{101}\approx10.05\). Neither number is intrinsically more “true”; they encode different choices about how the Features should matter. A laboratory should test whether a scaling decision is appropriate for the task rather than assume every variable must be standardized.

Standardization with observed statistics

Standardization often uses \(z=(x-\bar x)/s\), where \(\bar x\) is the Training mean and \(s\) is the Training sample Standard Deviation. For the six illustrative temperatures, \(\bar x=72.5\)°C and \(s\approx9.354\)°C. Machine A therefore has standardized temperature \((60-72.5)/9.354\approx-1.336\). The standardized variable is unitless because the numerator and denominator have the same unit.

Do not confuse that standardized z-score with the linear score \(z=b+\mathbf{w}^T\mathbf{x}\) from Section 4. The letter is common, but the meaning comes from context.

Leakage warning. In a real Machine Learning workflow, means and standard deviations must be learned on Training, then reused unchanged on Validation, Test and future records. Using held-out data to compute the scaler lets evaluation observations influence the model pipeline.

Scaling is especially important for k-NN, k-Means, SVM, gradient-based optimization and many Regularization schemes. Tree splits are often relatively insensitive to monotonic scaling of individual numerical Features. “Always scale” is therefore too broad; students should understand the algorithm's mathematical mechanism.

Calculate one distance after Standardization

Take machines A and B again. Their temperature difference is 10°C and vibration difference is 1 mm/s. Using sample standard deviations 9.354°C and 1.871 mm/s, their standardized differences are approximately \(10/9.354=1.069\) and \(1/1.871=0.534\). Their standardized Euclidean distance is \(\sqrt{1.069^2+0.534^2}\approx1.195\). Compare this with the raw numerical distance \(\sqrt{101}\approx10.05\). Because this is a pairwise difference, subtracting the same Training mean from each observation cancels; dividing by the Training scale does not. That is why Scaling changes geometric distance even though it preserves the ordering of a single numerical Feature.

8. Covariance, Correlation, and dependence between Features

Before modeling, we often want to know whether two Features move together. Their Covariance summarizes whether above-average temperature tends to accompany above-average vibration. Correlation rescales covariance into a dimensionless value between −1 and 1 when both standard deviations are nonzero.

From our six observations, mean temperature is 72.5°C and mean vibration is 4.5 mm/s. We calculate deviations and products rather than skipping to a library result.

Machine T − 72.5 V − 4.5 Product
A −12.5 −2.5 31.25
B −2.5 −1.5 3.75
C −7.5 −0.5 3.75
D 7.5 1.5 11.25
E 2.5 0.5 1.25
F 12.5 2.5 31.25
Total 82.50

The sample Covariance divides the sum by \(n-1=5\), not 6:

\[s_{TV}=\frac{82.5}{5}=16.5\ \mathrm{(^{\circ}C)(mm/s)}.\]

The sample variances are \(s_T^2=87.5\) °C² and \(s_V^2=3.5\) (mm/s)², so their sample standard deviations are \(\sqrt{87.5}\approx9.354\)°C and \(\sqrt{3.5}\approx1.871\) mm/s. Therefore

\[r_{TV}=\frac{16.5}{\sqrt{87.5}\sqrt{3.5}}\approx0.943.\]

A positive correlation close to 1 means these six readings tend to rise together in a roughly linear way. It does not establish that temperature causes vibration, that either causes failure, or that the association would persist in other machines. Only six deliberately constructed observations were used; the high correlation has no statistical generalizability claim.

Why this matters for ML

Strongly related Features can provide redundant information. In some linear models they can make coefficients unstable and complicate individual interpretation even if predictions remain useful. In PCA, covariance and eigenvectors help identify directions of joint variation. Later dedicated guides develop those consequences mathematically.

Verify where the variance numbers came from

For temperatures, deviations from 72.5 are \(-12.5,-2.5,-7.5,7.5,2.5,12.5\). Squaring and adding gives \(156.25+6.25+56.25+56.25+6.25+156.25=437.5\); dividing by five gives \(s_T^2=87.5\). For vibration, squared deviations sum to 17.5, hence \(s_V^2=17.5/5=3.5\). These denominators match the sample covariance. If temperature were measured in degrees Fahrenheit instead of Celsius, the numeric covariance would change with the unit conversion, while the correlation would remain unchanged under a positive linear rescaling. This is why Correlation is often more convenient for comparisons across measurement units.

9. Functions and the Sigmoid: mapping a score into a probability-like output

A function assigns an output to each permitted input. The score \(z=-4+0.04T+0.30V\) is an affine function of the sensor readings. It may be transformed through the Sigmoid Function:

\[\sigma(z)=\frac{1}{1+e^{-z}}.\]

For any finite real input \(z\), the output falls strictly between 0 and 1. At \(z=0\), \(\sigma(0)=1/(1+1)=0.5\). For machine A, \(z=-1\), so \(\sigma(-1)=1/(1+e^{1})\approx0.2689\). Machine F has \(z=1.5\), giving \(\sigma(1.5)=1/(1+e^{-1.5})\approx0.8176\).

Machine Linear score z Sigmoid output Predicted label at threshold 0.50 Actual y
A −1.00 0.2689 0 0
B −0.30 0.4256 0 1
C −0.20 0.4502 0 0
D 1.00 0.7311 1 1
E 0.50 0.6225 1 0
F 1.50 0.8176 1 1

The model flags D, E and F. Compared with the actual labels, this gives \(TP=2\) (D, F), \(FP=1\) (E), \(FN=1\) (B), and \(TN=2\) (A, C). Thus Accuracy is \((2+2)/6=66.67\%\). We should not say the six Sigmoid outputs are calibrated failure probabilities: the coefficients were invented and never fitted or validated. “Probability-like” describes the mathematical range and potential modeling interpretation, not verified empirical accuracy.

A Decision Threshold is a rule that converts a score or estimated probability into a label. Changing the cutoff changes decisions but does not change the underlying Sigmoid scores. Later guides explain learning the coefficients and selecting thresholds using held-out data.

10. Derivatives: understanding the rate of change

Calculus begins with the question: how quickly does an output change when an input changes? For \(f(x)=x^2\), increasing \(x\) from 3 to 3.1 changes the output from 9 to 9.61. The average change per unit of x over that interval is \((9.61-9)/(3.1-3)=6.1\).

A Derivative measures the limiting change per unit of input as the step becomes very small:

\[f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}.\]

Substitute \(f(x)=x^2\) and expand:

\[\frac{(x+h)^2-x^2}{h}=\frac{x^2+2xh+h^2-x^2}{h}=2x+h.\]

Taking \(h\to0\) yields \(f'(x)=2x\). At \(x=3\), the instantaneous slope is 6, consistent with the finite-step estimate 6.1 approaching 6 as the step shrinks.

Interpreting signs and units

A positive derivative means the function rises locally with increasing input; a negative derivative means it falls. A derivative of zero indicates a stationary point but does not by itself prove a minimum. The derivative's units are “output units per input unit.” For the hypothetical linear score, \(\partial z/\partial T=0.04\) per °C and \(\partial z/\partial V=0.30\) per mm/s.

The Sigmoid derivative is \(\sigma'(z)=\sigma(z)[1-\sigma(z)]\). At \(z=0\), this equals \(0.5(1-0.5)=0.25\). Consequently, a small score change of 0.1 near zero changes the Sigmoid output by approximately 0.025 (a local approximation), not by 0.1. This is the beginning of understanding how models change predictions when parameters change.

Why students need derivatives. Optimization algorithms must know—or estimate—how the objective changes when a model parameter moves. Derivatives provide that local directional information; their existence does not guarantee that a particular update will improve performance for an arbitrarily large step.

Check the limiting idea from both directions

A smaller forward step from 3 to 3.01 produces \([(3.01)^2-3^2]/0.01=(9.0601-9)/0.01=6.01\). A symmetric finite difference provides \([f(3+h)-f(3-h)]/(2h)\); for \(f(x)=x^2\) this simplifies exactly to 6 for any nonzero h. Such numerical differences can approximate derivatives in code and help test hand calculations. However, roundoff error and measurement noise matter when h becomes extremely small. An analytic derivative avoids that particular approximation error when it is available and correctly derived.

A derivative is a tangent slope, not a mysterious rule

This graph connects the difference quotient with geometry. For \(f(x)=x^2\), the point of interest is \((3,f(3))=(3,9)\). The derivative is \(f'(3)=2(3)=6\), so the tangent line obeys \(y-9=6(x-3)\), or equivalently \(y=6x-9\).

Verify the slope. Along the tangent, moving from \(x=3\) to \(x=4\) raises the line from 9 to 15. Thus \((15-9)/(4-3)=6\). But the original curve reaches \(f(4)=16\). The tangent approximates the curve locally around 3; it does not replace it everywhere.

11. Partial Derivatives and the Gradient: several parameters can change together

ML objectives usually depend on more than one adjustable parameter. A Partial Derivative measures change in one variable while holding the others constant. The Gradient collects the partial derivatives into a vector pointing in the direction of steepest local increase in Euclidean parameter coordinates.

Consider the transparent two-parameter objective

\[L(w,b)=(w-3)^2+(b+1)^2.\]

We can regard \(L\) as a mathematical loss surface, not as a fitted loss from our six machines. The minimum occurs at \(w=3\), \(b=-1\), where both squares are zero. Holding \(b\) fixed, differentiating the first term gives \(\partial L/\partial w=2(w-3)\); holding \(w\) fixed gives \(\partial L/\partial b=2(b+1)\). Thus:

\[\nabla L(w,b)=\begin{bmatrix}2(w-3)\\2(b+1)\end{bmatrix}.\]

At the initial point \((w,b)=(0,0)\), the loss is \(L=9+1=10\) and the gradient is \([-6,2]^T\). To decrease the loss locally, move against the gradient: increase \(w\) and decrease \(b\). For learning rate \(\eta=0.2\), the simultaneous update is

\[\begin{bmatrix}w_{new}\\b_{new}\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}-0.2\begin{bmatrix}-6\\2\end{bmatrix}=\begin{bmatrix}1.2\\-0.4\end{bmatrix}.\]

Recalculate rather than assume improvement: \(L(1.2,-0.4)=(1.2-3)^2+(-0.4+1)^2=3.24+0.36=3.60\). The loss decreased from 10 to 3.6.

Why is this not just two independent derivatives? The gradient unifies the direction of a joint parameter update. In nonlinear ML problems, parameters can interact, changing each partial derivative as the other parameters change. The local step is useful only if the learning rate and objective geometry support it.

12. The Chain Rule: tracing influence through multiple functions

Modern models apply functions inside other functions. For our two-sensor score, let \(z=b+w_TT+w_VV\) and \(p=\sigma(z)\). If we change \(w_T\), the probability-like output changes indirectly through \(z\). The Chain Rule connects the effects:

\[\frac{\partial p}{\partial w_T}=\frac{dp}{dz}\frac{\partial z}{\partial w_T}=p(1-p)T.\]

This is a product of two derivatives, not the product of the original two functions. At machine A, \(T=60\) and \(p\approx0.26894\). Therefore \(\partial p/\partial w_T\approx0.26894(0.73106)(60)\approx11.797\) per unit change of the temperature weight. The number seems large because \(w_T\) itself is expressed per °C; changing that weight by a full unit would be enormous. A small change of \(0.001\) suggests a local probability change of roughly \(0.0118\), so scale matters in interpreting derivatives.

From a probability output to a Loss Function

For a binary label \(y\in\{0,1\}\) and probability output \(p\), Binary Cross-Entropy (Log Loss) for one observation is

\[\ell(y,p)=-\big[y\ln(p)+(1-y)\ln(1-p)\big].\]

If \(y=1\), this becomes \(-\ln p\): predicting a small probability for an event that occurs receives a large penalty. If \(y=0\), it becomes \(-\ln(1-p)\). A perfect prediction approaches loss zero, while confidently wrong probabilities receive very large losses.

Applying the Chain Rule through the Sigmoid yields the important simplification \(\partial\ell/\partial z=p-y\). Hence \(\partial\ell/\partial w_T=(p-y)T\) and \(\partial\ell/\partial b=p-y\). This derivative is with respect to a model parameter and is different from a derivative with respect to the observed temperature reading.

For machine A, with actual \(y=0\), the score is \(-1\) and \(p\approx0.26894\), giving \(\partial\ell/\partial z\approx0.26894\). For machine B, whose label is 1 but whose \(p\approx0.42556\), the corresponding derivative is \(-0.57444\). Their signs indicate different local pressures on the predicted scores.

Interpretation boundary. The mathematical derivative shows what happens to the loss when the *model score* changes locally. It does not establish a causal effect of manipulating a real machine's temperature or vibration.

Derive the important Log Loss simplification

For one observation, begin with \(\ell=-y\ln(p)-(1-y)\ln(1-p)\). Differentiating with respect to \(p\) gives \(\partial\ell/\partial p=-y/p+(1-y)/(1-p)\). The Sigmoid derivative gives \(dp/dz=p(1-p)\). Multiply with the Chain Rule: \([-y/p+(1-y)/(1-p)]p(1-p)=-y(1-p)+(1-y)p=p-y\). No mysterious shortcut occurred. The familiar gradient formula is the result of applying the derivatives in the correct order. For a dataset, average the individual parameter gradients according to the definition of the chosen Loss Function.

13. Gradient Descent: applying the calculus to learning

Gradient Descent uses repeated parameter updates to reduce an objective. At iteration \(t\), a generic update is \(\boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\nabla L(\boldsymbol\theta_t)\), where \(\eta>0\) is the Learning Rate. The gradient describes local direction; the learning rate determines how far to move.

First, see every step for a quadratic objective

Let \(L(w)=(w-3)^2\), so \(L'(w)=2(w-3)\). Start at \(w_0=0\), choose \(\eta=0.2\), and compute two updates:

\[w_1=0-0.2[-6]=1.2,\quad L(w_1)=(1.2-3)^2=3.24.\]
\[w_2=1.2-0.2[-3.6]=1.92,\quad L(w_2)=(1.92-3)^2=1.1664.\]

The initial loss was 9, so the sequence \(9\to3.24\to1.1664\) makes the improvement visible. This simple convex parabola has a unique minimum at \(w=3\). Real ML objectives can have plateaus, poor conditioning, local minima or other complications; the example establishes mechanics, not universal convergence.

Then make one data-based Logistic update

Use only two observations from our machine table: machine A has vibration 2 and label 0; machine F has vibration 7 and label 1. Define a scaled input \(x=V/10\), so \((x_1,y_1)=(0.2,0)\) and \((x_2,y_2)=(0.7,1)\). This is a separate one-feature training demonstration, not the already hand-specified two-feature score.

Start a Logistic model at \(w=0,b=0\): both linear scores are zero and both outputs are \(p_1=p_2=0.5\). The average Binary Cross-Entropy is \(L=-[\ln(0.5)+\ln(0.5)]/2\approx0.693147\). The batch gradients are

\[\frac{\partial L}{\partial w}=\frac{(0.5-0)(0.2)+(0.5-1)(0.7)}{2}=\frac{0.10-0.35}{2}=-0.125,\]
\[\frac{\partial L}{\partial b}=\frac{(0.5-0)+(0.5-1)}{2}=0.\]

With \(\eta=1\), the update is \(w_{new}=0-1(-0.125)=0.125\) and \(b_{new}=0\). The new probabilities are \(\sigma(0.125\times0.2)\approx0.50625\) and \(\sigma(0.125\times0.7)\approx0.52186\). Their average loss is now approximately 0.67804, less than 0.69315. We recalculated it independently: a gradient formula alone does not prove the step improved the loss.

Learning Rate trade-off. Too small a step can require many iterations; too large a step can overshoot the minimum or diverge. Later we distinguish Batch, Stochastic and Mini-Batch Gradient Descent and explore more sophisticated optimizers.

Verify why the Learning Rate cannot be arbitrary

The same quadratic exposes overshooting. Start at \(w_0=0\), where the gradient is −6. With \(\eta=1\), the update is \(w_1=0-1(-6)=6\), and the loss remains \((6-3)^2=9\): one very large jump failed to improve the objective. With \(\eta=1.2\), the update would be \(w_1=7.2\), making the loss \((7.2-3)^2=17.64\), worse than the initial 9. This calculation explains what “overshoot” actually means, rather than asking students to memorize the term.

14. Probability: events, frequencies, and conditional questions

Probability formalizes uncertainty about events. In our synthetic table let \(F\) mean “failure occurs in the next 30 days” and \(H\) mean “vibration is at least 5 mm/s.” There are three failures (B, D, F) among six machines, so the observed share is \(P(F)=3/6=0.5\). Writing \(P\) here means an empirical proportion calculated from a teaching dataset, not an established population probability.

Machines D, E and F have high vibration; among those three, D and F fail. The observed conditional failure share is:

\[P(F\mid H)=\frac{\#(F\cap H)}{\#(H)}=\frac{2}{3}\approx0.667.\]

The symbol \(\cap\) denotes the intersection (“both events occur”) and the vertical bar \(\mid\) means “given that.” Among the machines with vibration below 5, only B fails, giving \(P(F\mid H^c)=1/3\). The superscript \(c\) denotes the complement (“not high vibration”).

Observed group Failure (F) No failure Total
High vibration H (≥5) 2 1 3
Lower vibration Hᶜ (<5) 1 2 3
Total 3 3 6

Conditional direction matters

\(P(F\mid H)\) asks “among high-vibration machines, what fraction failed?” The reversed \(P(H\mid F)=2/3\) asks “among machines that failed, what fraction had high vibration?” These happen to have the same numerical value in this balanced tiny table, but they answer different questions and are not generally equal. That accidental equality is exactly why a second numerical example is needed.

For events with positive denominators, the Multiplication Rule is \(P(F\cap H)=P(F\mid H)P(H)\). In this table, \((2/3)(3/6)=2/6\), matching the two joint occurrences among six machines. This provides an arithmetic consistency check.

Careful interpretation. A 2/3 empirical share based on three machines is fragile. It is neither a causal finding nor a reliable 66.7% failure probability for a future industrial population. A real dataset needs representative observations and uncertainty assessment.

Independence is a mathematical claim, not a vague resemblance

Events \(F\) and \(H\) are independent if \(P(F\mid H)=P(F)\) when \(P(H)>0\), equivalently \(P(F\cap H)=P(F)P(H)\). In the observed teaching table, \(P(F\mid H)=2/3\) whereas \(P(F)=1/2\). The empirical proportions therefore do not satisfy the independence equality. This calculation alone cannot establish a population-level dependence with statistical confidence: the table has only six deliberately chosen observations. Independence is a structural property of a probability distribution, not something proved by a single apparent pattern.

15. Bayes' Theorem and the base-rate problem

Bayes' Theorem relates conditional probabilities in opposite directions. For a positive warning signal \(+\) and failure \(F\), it takes the form

\[P(F\mid +)=\frac{P(+\mid F)P(F)}{P(+\mid F)P(F)+P(+\mid F^c)P(F^c)}.\]

The terms have specific roles: \(P(F)\) is the Prior failure probability; \(P(+\mid F)\) is the Sensitivity or True Positive Rate; \(P(+\mid F^c)\) is the False Positive Rate, equal to 1 − Specificity; and \(P(F\mid+)\) is the Posterior probability of failure after observing a positive warning.

A different, explicitly hypothetical operating population

Imagine 1,000 machines, 10% of which fail during the stated horizon. Suppose a warning detector catches 80% of actual failures and incorrectly warns on 10% of non-failures. These rates are assumed solely for this exercise, not estimated from our six-row dataset.

Actual status Detector positive Detector negative Total
Failure 80 20 100
No failure 90 810 900
Total 170 830 1,000

Why 90 False Positives? Of 900 machines without failure, 10% are flagged: \(0.10\times900=90\). Therefore the proportion of positive warnings corresponding to actual failures is

\[P(F\mid +)=\frac{80}{80+90}=\frac{80}{170}\approx0.4706=47.06\%.\]

The Bayes calculation gives the same result: \((0.8)(0.1)/[(0.8)(0.1)+(0.1)(0.9)]=0.08/0.17\). Even with 80% sensitivity, less than half of positive alerts represent actual failures in this assumed population, because failures are relatively uncommon and there are many non-failing machines.

What changes if prevalence changes?

If the same detector were used where 50% of machines fail, then \(P(F\mid+)=(0.8\times0.5)/[(0.8\times0.5)+(0.1\times0.5)]=0.4/0.45\approx88.89\%\). Sensitivity and False Positive Rate stayed fixed; only the base rate changed. This does not prove the detector maintains identical error rates across populations—it isolates one mathematical effect.

Applied lesson. For rare events, Precision (Positive Predictive Value) depends heavily on prevalence. Reporting Sensitivity without describing the population can mislead a safety team deciding how many alerts need human inspection.

Interpret a negative warning as carefully as a positive one

The same 1,000-machine table contains 830 negative detector results. Among them, 20 machines nevertheless fail and 810 do not. Thus the conditional failure share after a negative warning is \(P(F\mid-) =20/(20+810)=20/830\approx2.41\%\). The Negative Predictive Value, the share of negative results that are truly nonfailures, is \(810/830\approx97.59\%\). Those two percentages describe complementary events among the negative-warning population. Neither is the detector's Sensitivity or Specificity, and both depend on the assumed prevalence.

Probability tree: reconstruct all four possible outcomes

The tree arranges the same hypothetical population of 1,000 machines in two stages: first by actual failure status, then by detector output. The branch probabilities at every split sum to one: \(0.10+0.90=1\), \(0.80+0.20=1\) and \(0.10+0.90=1\).

Why the denominator matters. The probability of a positive detector signal is \(P(+)=0.8(0.1)+0.1(0.9)=0.08+0.09=0.17\); therefore among all positive alerts \(P(F\mid +)=0.08/0.17=8/17\approx47.06\%\). Do not divide by the 100 actual failures: the conditioning event is a positive alert, not an actual failure.

16. Random Variables, Expected Value, Variance, and Standard Deviation

A Random Variable represents a numerical outcome of an uncertain process. A binary indicator \(Y=1\) for failure and 0 otherwise is a Bernoulli-type outcome. For a Bernoulli variable with event probability \(p\), its population mean is \(E[Y]=p\) and variance is \(\operatorname{Var}(Y)=p(1-p)\). If \(p=0.1\), this variance is \(0.1(0.9)=0.09\), rather than 0.1.

Work through the vibration readings

The six measured vibrations are \(2,3,4,6,5,7\) mm/s. Their sample mean is

\[\bar V=\frac{2+3+4+6+5+7}{6}=\frac{27}{6}=4.5\ \mathrm{mm/s}.\]

Subtract 4.5 from each reading: \(-2.5,-1.5,-0.5,1.5,0.5,2.5\). Square those deviations: \(6.25,2.25,0.25,2.25,0.25,6.25\), summing to 17.5. The sample variance divides by \(n-1\):

\[s_V^2=\frac{17.5}{6-1}=3.5\ \mathrm{(mm/s)^2},\qquad s_V=\sqrt{3.5}\approx1.871\ \mathrm{mm/s}.\]

If these six readings were defined as the entire population of interest, the corresponding population variance would divide by 6: \(17.5/6\approx2.917\). The choice of divisor depends on whether we are describing a population or estimating variation from a sample, not on whether one formula “looks cleaner.”

Expected loss under uncertain outcomes

Suppose an inspection policy has a 10% chance of a missed failure costing $100 and a 90% chance of no loss. Its expected loss per decision is \(E[C]=0.1(100)+0.9(0)=\$10\). This is an expectation under an assumed model of probabilities and costs, not a guarantee that each inspection costs exactly $10.

Using the confusion counts from Section 9 (one False Positive and one False Negative), suppose each FP costs $10 and each FN costs $100. The realized illustrative cost over six machines is \(10(1)+100(1)=\$110\), or \(110/6\approx\$18.33\) per machine. That realized sample average and the earlier hypothetical expected cost are different quantities from different assumptions.

Distinguish three ideas. The mean summarizes the center of observed data, variance summarizes dispersion around that center, and Expected Value averages outcomes according to an assumed probability distribution. None by itself establishes that a predictive model will generalize.

17. Sampling, generalization, and a reproducible numerical laboratory

Why spend so much time on only six rows? Because small complete datasets make the mathematics visible. However, the same small dataset is inadequate for estimating reliable failure rates or assessing generalization. The three failures and three non-failures were constructed for instruction, making the observed 50% prevalence unrepresentative of any asserted industrial population.

Population, sample, parameter, statistic

The population is the set of machine-time situations where predictions would actually be used. Our six examples are a tiny illustrative sample. A population probability \(p\) is a parameter; an observed proportion such as \(\hat p=3/6=0.5\) is a statistic. An estimator is a procedure for obtaining such statistics from data. A meaningful study would document the sampling design, time periods, machine types and dependence between repeated measurements.

One machine measured every minute produces many rows but not necessarily many independent observations. If all records come from the same six units, a random row split could exaggerate performance by placing near-duplicates in Training and Test. Temporal and group-aware validation can be necessary, but it must reflect the real deployment question.

Reproduce the guide's calculations in Python

The following single code sample verifies the six sensor scores, the Sigmoid outputs, the sample covariance and the confusion counts. It does not fit an ML model or claim out-of-sample accuracy.

import numpy as np

sensor_data = np.array([[60, 2], [70, 3], [65, 4],
                        [80, 6], [75, 5], [85, 7]], dtype=float)
failures = np.array([0, 1, 0, 1, 0, 1])
weights = np.array([0.04, 0.30])
scores = sensor_data @ weights - 4
probabilities = 1 / (1 + np.exp(-scores))
predicted = (probabilities >= 0.5).astype(int)

print('scores:', np.round(scores, 2))
print('sigmoid:', np.round(probabilities, 4))
print('sample covariance:', np.cov(sensor_data, rowvar=False))
print('TP FP FN TN:', [int(np.sum((predicted == a) & (failures == b)))
                      for a, b in [(1, 1), (1, 0), (0, 1), (0, 0)]])

The expected scores are \([-1.0,-0.3,-0.2,1.0,0.5,1.5]\); the covariance matrix is \(\begin{bmatrix}87.5&16.5\\16.5&3.5\end{bmatrix}\); and the confusion counts are \([2,1,1,2]\). If your output differs, check column order, units, the intercept and whether sample covariance divides by \(n-1\).

The mathematical pipeline, in one sentence

Represent a snapshot as a vector; put snapshots into a matrix; compute a parameterized score; apply an output transformation; compare with appropriately obtained labels; calculate a loss; update parameters using derivatives; then evaluate new records without using their outcomes to design the model. Each arrow introduces assumptions worth auditing.

How much uncertainty can be hidden by a proportion?

As a purely illustrative calculation, the conventional standard-error expression for an independently sampled Bernoulli proportion is \(SE(\hat p)\approx\sqrt{\hat p(1-\hat p)/n}\). Plugging in \(\hat p=0.5\) and \(n=6\) gives \(\sqrt{0.25/6}\approx0.204\), or roughly 20.4 percentage points. This plug-in quantity is not a valid precise uncertainty guarantee for our synthetic, nonrandomly selected records; normal approximations are also unreliable for such a small sample. Its value is to make visible why a proportion based on six observations cannot justify confident production claims. A sound interval would require an appropriate sampling design and a method suitable for small n.

Verification lab: Matrix Multiplication and numerical derivatives

The following Python code adds two checks to the reproducible example above. First, it expresses two delivery-time predictions in one matrix multiplication. Next, it compares the analytic gradient of the small Logistic Loss in Section 13 with a central finite-difference approximation. The numerical method perturbs one parameter at a time and recomputes the Loss; it is therefore an independent check of the derivative formula.

The two deliveries are entirely synthetic. Each row holds [1, distance in km, number of stops]; the leading 1 represents the Intercept. Coefficient units are minutes, minutes/km and minutes/stop. Consequently, the output is measured in minutes—not kilometers or probabilities.

\[X_{delivery}=\begin{bmatrix}1&4&2\\1&6&1\end{bmatrix},\quad \theta=\begin{bmatrix}8\\3\\5\end{bmatrix},\quad \widehat t=X_{delivery}\theta=\begin{bmatrix}8+12+10\\8+18+5\end{bmatrix}=\begin{bmatrix}30\\31\end{bmatrix}\,\text{min}.\]
import numpy as np

# Two synthetic deliveries: intercept, distance (km), stops
routes = np.array([[1.0, 4.0, 2.0], [1.0, 6.0, 1.0]])
minutes_per_feature = np.array([8.0, 3.0, 5.0])
eta_minutes = routes @ minutes_per_feature
assert np.allclose(eta_minutes, [30.0, 31.0])
print('delivery minutes:', eta_minutes)

# The two-sample Logistic Loss from Section 13
x = np.array([0.2, 0.7])
y = np.array([0.0, 1.0])
def loss(w, b):
    z = w * x + b
    return np.mean(np.logaddexp(0.0, z) - y * z)

h = 1e-5
numerical_w = (loss(h, 0.0) - loss(-h, 0.0)) / (2 * h)
numerical_b = (loss(0.0, h) - loss(0.0, -h)) / (2 * h)
analytic = np.array([-0.125, 0.0])
assert np.allclose([numerical_w, numerical_b], analytic, atol=1e-8)
print('numerical gradient:', np.round([numerical_w, numerical_b], 6))
print('analytic gradient:', analytic)

Expected output: delivery minutes: [30. 31.], numerical gradient: [-0.125 0.] and analytic gradient: [-0.125 0.]. We choose \(h=10^{-5}\) because it is small enough for this smooth example without needlessly amplifying floating-point roundoff. Numerical agreement complements—but does not replace—the Chain Rule derivation in Section 12.

18. Common mistakes: recognize and correct the reasoning

1. Treating units as interchangeable

Adding 60°C to 2 mm/s does not create a physically meaningful measurement. A weighted score requires explicit coefficients and a coherent interpretation; rescaling changes what coefficients mean.

2. Confusing a row with a column

A 6×2 dataset has six machines and two Features. A 2×6 transpose is not a second version of the same dataset layout unless downstream operations are revised consistently.

3. Multiplying matrices entry by entry

Matrix multiplication uses row–column Dot Products. The matrices in Section 6 give AB = [[4,10],[10,20]], not the entrywise product [[2,0],[3,20]].

4. Assuming raw Euclidean distance is objective similarity

The numerical size of temperature differences can overwhelm vibration differences. Choice of Features, units, distance and Scaling determines what “nearby” means.

5. Interpreting Correlation as causation

Our correlation of about 0.943 shows joint variation in six synthetic observations. It does not prove that changing temperature changes vibration or prevents failure.

6. Treating a derivative as an average over a large interval

The derivative of x² at 3 is 6, whereas the average change from 3 to 3.1 is 6.1. A local derivative is a limit, not a guarantee about a large intervention.

7. Assuming a zero derivative guarantees the best solution

A stationary point may be a minimum, maximum or saddle point. Examine objective geometry, constraints and behavior around the point.

8. Forgetting the Chain Rule

When parameters affect a loss through an intermediate score and Sigmoid, differentiate the entire path. For binary Log Loss, this produces the compact but derived gradient (p−y)x.

9. Assuming Gradient Descent always decreases loss

The update follows a local direction; an excessive Learning Rate can overshoot or diverge. Recompute loss after the step to verify the effect.

10. Reversing conditional probabilities

P(failure | warning) is not generally P(warning | failure). Base rates and False Positives matter, as the 1,000-machine Bayes example demonstrates.

11. Confusing sample and population variance

For our vibration deviations the sum of squares is 17.5. Dividing by 5 yields sample variance 3.5; dividing by 6 yields population variance about 2.917. Name the quantity before choosing the divisor.

12. Believing a synthetic perfect-looking pattern proves generalization

Our six rows are designed to be teachable; invented scores are not calibrated probabilities. A real deployment demands external validation, representative outcomes and monitoring.

19. Knowledge checks: reason before revealing the solution

1. For machine D, write the Feature vector, dimensions, and label.

Worked solution

Machine D is the fourth row: \(\mathbf{x}_D=[80,6]^T\in\mathbb{R}^2\); temperature is 80°C, vibration is 6 mm/s, and \(y_D=1\). This describes observed historical data; it does not assert that D's failure was known at the prediction snapshot.

2. What is the raw Euclidean distance from A to D?

Worked solution

Subtract: \([80-60,6-2]=[20,4]\). Square entries and add: \(20^2+4^2=400+16=416\). Take the square root: \(\sqrt{416}\approx20.396\). Since units differ, interpret it as a coordinate distance rather than a physical quantity in a single unit.

3. Calculate the Dot Product score for machine C.

Worked solution

C has temperature 65°C and vibration 4 mm/s. Using \(z=-4+0.04T+0.30V\): \(-4+0.04(65)+0.30(4)=-4+2.60+1.20=-0.20\). The score is not a probability until transformed.

4. What are the shapes of X, θ, and Xθ after adding an intercept?

Worked solution

The Design Matrix \(\widetilde X\) has shape 6×3, the parameter vector \(\boldsymbol\theta\) has shape 3×1, and the product is 6×1. The shared inner dimension 3 allows the multiplication; each result corresponds to one machine.

5. Compute the bottom-right entry of AB in Section 6.

Worked solution

Take row 2 of A, \([3,4]\), and column 2 of B, \([0,5]^T\). Their Dot Product is \(3(0)+4(5)=20\). Entrywise multiplication would not follow the matrix-product definition.

6. What is the standardized temperature of A using the sample statistics?

Worked solution

The Training mean in the illustration is 72.5°C and sample standard deviation approximately 9.354°C. Subtract and divide: \((60-72.5)/9.354\approx-1.336\). The standardized value is unitless and signals A is below the sample mean.

7. Recalculate sample covariance between temperature and vibration.

Worked solution

Means: 72.5 and 4.5. The six cross-products are 31.25, 3.75, 3.75, 11.25, 1.25 and 31.25, totaling 82.5. With six observations the sample divisor is 5: \(82.5/5=16.5\) (°C)(mm/s).

8. Convert A's score to a Sigmoid output and interpret it carefully.

Worked solution

For A, \(z=-1\), so \(\sigma(-1)=1/(1+e^1)\approx0.2689\). It is below the illustrative threshold 0.5 and predicts class 0. Since the coefficients were invented, do not claim this is a validated 26.89% failure risk.

9. Derive the derivative of x² at x=3.

Worked solution

Expand \([(x+h)^2-x^2]/h=2x+h\) for nonzero h, then let h approach zero to obtain \(2x\). Evaluate at 3: \(f'(3)=6\). This is instantaneous change per unit x.

10. Compute the gradient of L(w,b) at (0,0) and a step with η=0.2.

Worked solution

For \(L=(w-3)^2+(b+1)^2\), the gradient is \([2(w-3),2(b+1)]^T\). At zero it is \([-6,2]^T\). Update against it: \([0,0]^T-0.2[-6,2]^T=[1.2,-0.4]^T\). The loss decreases from 10 to 3.6.

11. Carry out a second quadratic Gradient Descent step from w=1.2.

Worked solution

For \(L=(w-3)^2\), \(L'(1.2)=2(1.2-3)=-3.6\). With \(\eta=0.2\), \(w_2=1.2-0.2(-3.6)=1.92\). The new loss is \((1.92-3)^2=1.1664\), less than 3.24.

12. What are the Confusion Matrix counts for the hypothetical Sigmoid labels?

Worked solution

At threshold 0.5 the predictions are [0,0,0,1,1,1]; actual labels are [0,1,0,1,0,1]. D and F are TP (2), E is FP (1), B is FN (1), and A and C are TN (2). Accuracy is \((2+2)/6=4/6\approx66.67\%\).

13. From the six machines, compute P(failure | high vibration).

Worked solution

High vibration (≥5 mm/s) occurs for D, E and F. D and F fail, whereas E does not. Therefore the empirical conditional share is \(2/3\approx66.67\%\). The denominator is the high-vibration group of three, not all six machines.

14. Why is a warning detector with 80% Sensitivity not necessarily 80% precise?

Worked solution

Out of 1,000 machines with 100 failures and 900 non-failures, sensitivity 80% detects 80 failures. A 10% False Positive Rate flags 90 non-failures. Of 170 positive warnings, only 80 are true: Precision \(=80/170\approx47.06\%\). The base rate changes the positive-alert composition.

15. Calculate the sample variance of vibrations and give its units.

Worked solution

The six vibrations have mean 4.5. Squared deviations sum to 17.5. Sample variance \(=17.5/(6-1)=3.5\) (mm/s)²; sample standard deviation \(=\sqrt{3.5}\approx1.871\) mm/s. Variance has squared units; standard deviation has the original units.

16. Name two reasons six machines cannot establish production performance.

Worked solution

The sample is extremely small and intentionally constructed, making its 50% failure share potentially unrepresentative; also, readings may be dependent by machine type, time or maintenance history. A valid evaluation needs representative, independent or appropriately grouped outcomes and an untuned held-out process.

Transfer practice: four problems beyond the six original machines

Try each before revealing its solution. These scenarios and figures are hypothetical learning examples, not estimates from operational fleets.

17. Two deliveries: verify shapes, products, and units.

The Feature Matrix including an Intercept is \(X=\begin{bmatrix}1&4&2\\1&6&1\end{bmatrix}\), and the coefficient vector is \(\theta=[8,3,5]^T\). (a) What are their shapes? (b) Calculate both predictions. (c) Why are outputs measured in minutes?

Worked solution. (a) \(X\) is 2×3, \(\theta\) is 3×1, and \(X\theta\) is 2×1. (b) First row: \(1(8)+4(3)+2(5)=8+12+10=30\) minutes. Second row: \(1(8)+6(3)+1(5)=8+18+5=31\) minutes. (c) Each term has time units: 8 minutes, kilometers times minutes/km, and stops times minutes/stop. These are assumed coefficients, not values learned from an actual dataset.

18. A tangent is not the entire curve.

For \(f(x)=x^2\) at \(x=3\), derive the tangent, approximate \(f(3.2)\) linearly, and compare it with the exact function.

Worked solution. \(f(3)=9\) and \(f'(3)=2(3)=6\). The tangent is \(y-9=6(x-3)\). At 3.2, it predicts \(9+6(0.2)=10.2\); the exact result is \(3.2^2=10.24\). The approximation error is \(10.24-10.2=0.04\), positive because this quadratic is convex.

19. Change the base rate: what does a positive alert mean?

A hypothetical detector has 80% Sensitivity and a 10% False Positive Rate. Change failure prevalence to 5% instead of 10%. For 2,000 machines, compute \(P(F\mid+)\), assuming the conditional detector rates remain fixed.

Worked solution. Expected failures: \(2000(0.05)=100\); non-failures: 1,900. True alerts: \(100(0.8)=80\). False alerts: \(1900(0.1)=190\). All positive alerts: \(80+190=270\). Therefore \(P(F\mid+)=80/270=8/27\approx29.63\%\). Lower prevalence reduces Positive Predictive Value even when Sensitivity stays 80%. These are expected counts in a hypothetical population, not evidence of real-world detector performance.

20. Check a gradient without memorizing a formula.

Given \(L(w)=(w-3)^2\), calculate the analytic derivative at \(w=2\) and verify it with a central finite difference of \(h=0.1\).

Worked solution. Analytically, \(L'(w)=2(w-3)\), so \(L'(2)=2(-1)=-2\). For finite differences, \(L(2.1)=(2.1-3)^2=0.81\) and \(L(1.9)=(1.9-3)^2=1.21\). The central quotient is \((0.81-1.21)/0.2=-0.40/0.2=-2\). Here the result is exact because the quadratic centered differences simplify exactly; finite-step differences are not exact for every function.

20. Glossary and final synthesis

Scalar
One numerical value, with units where appropriate.
Feature
Input measurement available when a prediction is made.
Target
Observed outcome a supervised model is trained or evaluated against.
Vector
Ordered collection of numbers representing coordinates or parameters.
Matrix
Rectangular array of values with specified row and column meanings.
Transpose
Operation exchanging rows and columns.
Dot Product
Sum of pairwise products of matching vector coordinates.
Matrix Multiplication
Operation combining rows and columns through Dot Products.
Norm
Measure of vector magnitude based on a specified rule.
Feature Scaling
Changing numerical representations to control relative scales.
Covariance
Measure of joint deviations around the means, with product units.
Correlation
Standardized measure of linear association between nonconstant variables.
Sigmoid Function
Nonlinear mapping from real scores into (0,1).
Derivative
Instantaneous rate of change with respect to an input.
Partial Derivative
Rate of change in one input while holding other inputs fixed.
Gradient
Vector of partial derivatives of a scalar-valued function.
Chain Rule
Rule for differentiating functions of functions.
Loss Function
Quantity measuring how poorly predictions match targets under a chosen objective.
Learning Rate
Step-size parameter of an optimization update.
Conditional Probability
Probability of an event given that another event holds.
Prior / Posterior
Probability before / after incorporating evidence under Bayes' Theorem.
Expected Value
Probability-weighted average of possible numerical outcomes.
Variance
Average squared spread around a mean under a defined population or sample formula.
Generalization
Ability to perform usefully on appropriate unseen data.

A Machine Learning computation can now be read as a coherent chain: represent measured Features as vectors and matrices; combine them with parameterized operations; transform the resulting scores; quantify disagreement with observed outcomes; differentiate a learning objective to update parameters; and assess uncertainty using Probability and Statistics. Each step is mathematical, but its interpretation also depends on units, sampling design, data timing, and the meaning of the target.

This chapter is a foundation, not a substitute for dedicated treatments of Linear Regression, Optimization, Statistical Learning Theory, or Probability. In the next guides, we will develop those subjects with the same emphasis on complete numerical examples, transparent assumptions and reproducible calculations.
