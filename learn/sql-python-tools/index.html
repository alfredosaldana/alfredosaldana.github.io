SQL, Python & Tools

Una ruta práctica para trabajar con datos: Python, NumPy, pandas, SQL, EDA, visualización, Jupyter y herramientas de reproducibilidad.

Aprender → SQL, Python & Tools

Aprende las herramientas que un Data Scientist utiliza todos los días.

Esta ruta combina programación, manipulación de datos, SQL, análisis exploratorio y herramientas de trabajo. El objetivo no es memorizar sintaxis aislada, sino aprender un workflow reproducible para transformar datos crudos en análisis claros, verificables y reutilizables.

Comenzamos con Python y NumPy, avanzamos hacia pandas y data cleaning, después construimos fundamentos sólidos de SQL, y terminamos integrando EDA, visualización, Jupyter, Git/GitHub y gestión de environments.

Orden recomendado: sigue la secuencia si estás construyendo tus herramientas desde cero. Si ya manejas Python, puedes comenzar directamente con pandas o SQL y regresar a los fundamentos cuando necesites reforzarlos.

Secuencia de aprendizaje

La ruta avanza desde Python y NumPy hacia pandas y data cleaning, luego SQL, y termina con EDA, visualización, Jupyter, Git/GitHub y reproducibilidad.

¿Por qué este orden?

Primero construimos las bases de Python y NumPy para entender cómo representar y transformar información. Luego usamos pandas para trabajar con datasets tabulares, limpiar datos, agrupar, combinar tablas y manejar fechas.

Después introducimos SQL desde SELECT y WHERE hasta JOINs, CTEs y Window Functions, porque gran parte del trabajo real de Data Science comienza extrayendo y organizando información desde bases de datos.

Finalmente, EDA y visualización convierten los datos en evidencia interpretable, mientras que Jupyter, Git/GitHub, virtual environments y requirements.txt permiten documentar y reproducir el análisis de principio a fin.
