Tensors 101 with PyTorch

A four-notebook educational series designed to help students understand tensors deeply—not merely use them—by connecting mathematical structure, PyTorch syntax and the way data flows through neural networks.

Educational Project

1. Why tensors matter

A tensor is the basic data structure used throughout modern deep learning. Images, tabular records, sequences, model parameters, activations and gradients are all represented as tensors. The main purpose of this educational project is to move from the idea of a simple number to higher-dimensional data structures and then show how those structures are manipulated inside PyTorch.

Key idea: tensors are not a special “AI object” disconnected from mathematics. They generalize scalars, vectors and matrices to an arbitrary number of dimensions.

2. The tensor hierarchy

3. Rank, axes, shape and element count

These terms are related but not interchangeable.

Rank / ndim

The number of axes in the tensor. A matrix has rank 2 because it has two axes.

Axis

One direction through the data. For shape (32, 3, 224, 224), axis 0 is batch, axis 1 is channel, axis 2 is height and axis 3 is width.

Shape

A tuple containing the length of each axis. Shape completely describes the arrangement of values.

numel

Total number of scalar values. It equals the product of all shape dimensions.

numel = d₁ × d₂ × ··· × dₙ
If a tensor has shape (2, 3, 4), then numel = 2 × 3 × 4 = 24.
Mini example. A tensor with shape (4, 5, 6) has rank 3 and contains 4 × 5 × 6 = 120 elements.

4. Why shape is one of the most important concepts in deep learning

Neural-network layers expect data in specific structural formats. A large fraction of beginner errors are shape mismatches rather than complicated mathematical failures.

(batch, features)
Typical fully connected/tabular input.
(batch, channels, height, width)
Typical PyTorch image input.
(batch, sequence length, embedding dimension)
Typical sequence representation.
Shape reasoning example. Suppose x has shape (4, 5, 6). If we compute x.sum(dim=1), axis 1 disappears because the values along its length-5 dimension are summed. The output shape becomes (4, 6).

5. Data types: what is stored inside the tensor?

Every tensor has a dtype that determines how values are represented in memory. This affects precision, memory use and compatibility with PyTorch operations.

dtypeTypical useWhy it matters
torch.float32Model inputs, parameters, activations and gradientsStandard balance of precision and memory for deep learning.
torch.float16Mixed-precision trainingUses less memory and can accelerate supported GPU workloads.
torch.int64Class labels and indicesMany PyTorch loss functions require integer class labels.
torch.boolMasks and conditionsUseful for selecting or excluding elements.
Why dtype matters: a model with 100 million parameters uses about 400 MB for the parameter values alone in float32, but about 200 MB in float16. Precision choices therefore have real computational consequences.

6. Devices: CPU and GPU

A tensor must live somewhere physically. In PyTorch, that means normally CPU memory or GPU memory. Operations require participating tensors to be on the same device.

device = torch.device("cuda" if torch.cuda.is_available() else "cpu") x = torch.randn(32, 10, device=device)
Common mistake: adding a CPU tensor to a GPU tensor produces a device mismatch error. Device management is not optional in GPU-based workflows.

7. Creating tensors

PyTorch offers several creation strategies. The educational goal is not to memorize commands, but to understand when each one is appropriate.

torch.tensor([1.0, 2.0, 3.0]) # from known values torch.zeros(3, 4) # all zeros torch.ones(3, 4) # all ones torch.eye(4) # identity matrix torch.arange(0, 10) # integer sequence torch.linspace(0, 1, 5) # evenly spaced sequence torch.rand(3, 4) # uniform random values torch.randn(3, 4) # standard normal random values

For reproducibility, the notebooks also emphasize setting a random seed:

torch.manual_seed(42)

8. Indexing and slicing

Indexing asks for specific elements or regions of a tensor. The number of indices required reflects the tensor's rank.

x[i, j, k]
For a rank-3 tensor, three indices identify one scalar element.

Slicing allows us to preserve axes while selecting ranges. This matters when selecting a batch, subset of features, image region or sequence window.

Mini example. If x has shape (32, 10), then x[:, 0] selects the first feature for all 32 observations and returns shape (32,).

9. Reshaping: changing structure without changing data

Many deep-learning operations require the same numbers to be reorganized into a different shape. A reshape is legal only if the total element count is preserved.

∏ old dimensions = ∏ new dimensions
Mini example. A tensor of shape (2, 3, 4) has 24 elements. It can be reshaped to (6, 4), (8, 3), (24,) or (1, 24), because all contain 24 values.

Important PyTorch tools include reshape(), view(), unsqueeze(), squeeze(), transpose() and permute().

view() vs reshape(): view() requires a contiguous memory layout. reshape() is more flexible because it may create a copy when needed.

10. Broadcasting: doing mathematics across compatible shapes

Broadcasting lets PyTorch apply element-wise operations to tensors whose shapes are different but compatible. Starting from the last dimension and moving left, dimensions are compatible if they are equal, one of them is 1, or one tensor has no corresponding dimension.

Broadcasting example.

A has shape (3, 4) and b has shape (4,).
PyTorch interprets b as if it were repeated across the three rows.
The result A + b has shape (3, 4).
Why broadcasting matters: neural networks constantly add bias vectors to batches of activations. Broadcasting makes this efficient without physically duplicating the bias vector.

11. Element-wise operations versus matrix multiplication

These are mathematically different operations and one of the most important distinctions for beginners.

Element-wise: Cᵢⱼ = Aᵢⱼ Bᵢⱼ
In PyTorch: A * B
Matrix product: Cᵢⱼ = Σₖ Aᵢₖ Bₖⱼ
In PyTorch: A @ B or torch.matmul(A,B)
Matrix multiplication example. If A has shape (5, 3) and B has shape (3, 2), the inner dimensions match, so A @ B has shape (5, 2).

12. Reduction operations

A reduction combines many values into fewer values. Examples include sum, mean, maximum and minimum.

mean(x) = (1/n) Σᵢ xᵢ

The crucial question is always: along which axis?

Mini example. If x has shape (32, 10), then x.mean(dim=0) computes one mean for each feature across the 32 observations and returns shape (10,).

13. Activation functions

Activation functions introduce nonlinearity into neural networks. Without nonlinear activations, stacking multiple linear layers would still collapse to one overall linear transformation.

FunctionFormulaInterpretation
ReLUReLU(x)=max(0,x)Keeps positive values and clips negative values to zero.
Sigmoidσ(x)=1/(1+e−x)Maps any real number into (0,1); often used for binary probabilities.
Tanhtanh(x)Maps values to (−1,1) and is centered at zero.

14. How tensors flow through a neural network

A dense neural-network layer applies an affine transformation followed by an activation function:

z = XW + ba = φ(z)
X = batch of input features, W = weight matrix, b = bias vector, φ = activation function.
Shape example.

Input X: (32, 10)
Weights W: (10, 64)
Bias b: (64,)
Matrix product XW: (32, 64)
Broadcast b across 32 rows → output z: (32, 64).

This single example combines matrix multiplication, shape reasoning and broadcasting—the three tensor ideas students must understand before moving confidently into neural networks.

15. Automatic differentiation: why PyTorch tensors are more than arrays

When requires_grad=True, PyTorch records operations in a computational graph. During backpropagation, it applies the chain rule to compute how a loss changes with respect to model parameters.

∂L/∂w = (∂L/∂y)(∂y/∂w)
This is the chain rule behind gradient-based learning.
w = torch.tensor(2.0, requires_grad=True) y = w**2 y.backward() print(w.grad) # 4.0

Because y = w², the derivative is dy/dw = 2w. At w = 2, the gradient is 4.

16. Common tensor mistakes this project helps prevent

  • Confusing rank with the number of elements.
  • Ignoring the batch dimension.
  • Trying matrix multiplication with incompatible inner dimensions.
  • Mixing CPU and GPU tensors.
  • Using the wrong dtype for class labels.
  • Applying view() to non-contiguous tensors.
  • Reshaping without checking that the total number of elements is preserved.
  • Reducing along the wrong axis.
  • Confusing element-wise multiplication with matrix multiplication.
  • Relying on code without predicting the output shape first.

The repository is intentionally organized as a sequence. Each notebook builds on the previous one: first understanding what tensors are, then creating them, manipulating their structure, and finally using the operations that appear inside deep-learning models.

18. What this educational project teaches

  • Think in shapes before thinking in code.
  • Understand the mathematics behind PyTorch syntax.
  • Use rank, axes, dtype and devices precisely.
  • Recognize broadcasting and matrix multiplication as core neural-network mechanics.
  • Use PyTorch tensors as the bridge between linear algebra and deep learning.
  • Debug systematically by checking shape, dtype and device at every stage.
