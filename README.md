# Alfredo Saldana — Personal Website

Static personal website for GitHub Pages.

## Included
- Homepage
- Projects page + 3 project detail pages
- Learning materials page
- Open Box page
- About page
- Contact page
- Responsive CSS and navigation JavaScript
- Custom SVG illustrations and profile image

## Publish on GitHub Pages
1. Upload the contents of this folder to the **root** of `alfredosaldana.github.io`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save and wait for GitHub Pages to deploy.

## Before launch
- Replace the Formspree placeholder `YOUR_FORM_ID` in `contact.html` if you want the form to work.
- Replace SVG project illustrations with your final project visuals whenever they are ready.
- Add links to unpublished project repositories after publishing them.
- Later you can connect `alfredosaldana.com` in GitHub Pages or through your final hosting provider.
